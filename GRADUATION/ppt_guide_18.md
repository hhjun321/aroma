# 발표 PPT 가이드 — 장별 핵심 수식·흐름 요약

학위논문 『Context-Aware 데이터 증강 기반 산업용 결함 검출 연구』의 본론 4개 장(제3장~제6장)을 발표용으로 정리한다.
각 장은 저자의 게재 논문 1편에 대응하며, 논문 게재 순서가 아니라 **연구의 발전 흐름**에 따라 구성한다. 연구는 결함 패치 생성에서 출발하여 배치 위치 탐색, 형태·문맥 호환성의 데이터 기반 자동화, 도메인 특화 문맥 인지 생성으로 확장된다.

| 장 | 논문 | 핵심 질문 | 핵심 방법 |
|---|---|---|---|
| 3장 | 객체탐지 모델기반 장비 결함검출 방법에 대한 연구 (JANT 29(6), 2025) | 생성 증강이 검출에 효과 있나 | GAN·Diffusion 결함 패치 생성 + 기존 ROI 재배치, YOLOv8 |
| 4장 | 결함검출 모델 성능 개선을 위한 결함데이터 증강 방법에 대한 연구 (JANT 30(1), 2026) | 어디에 붙여야 자연스러운가 | ControlNet 생성 + 밝기 유사도 유효 ROI + Poisson blending |
| 5장 | AROMA: Adaptive ROI-based Morphology-Aware Augmentation (Appl. Sci. 16(18), 2026) | 배치 규칙을 데이터에서 자동 도출할 수 있나 | 결함 형태 × 배경 문맥 공동출현 통계 → 대칭 호환성 게이트, 5개 도메인 |
| 6장 | CASDA: Context-Aware Steel Defect Augmentation (Appl. Sci. 16(12), 2026) | 특정 도메인에서 생성까지 문맥을 반영할 수 있나 | 철강 특화 호환성 행렬 + 3채널 힌트 ControlNet 생성 + 품질 게이트 |

연구 문제는 두 축으로 정리된다. **P1 What to place**는 어떤 결함 패치를 생성·선택할 것인가의 문제이며 제3장과 제6장에서 다룬다. **P2 Where to place**는 결함 패치를 어떤 배경과 위치에 배치할 것인가의 문제이며 제4장과 제5장, 제6장에서 다룬다. 두 축은 제6장에서 문맥 조건부 생성과 배치로 결합된다.

## 1. 제3장 — 객체탐지 모델 기반 장비 결함검출

### 요약

제3장에서는 PKU-HRI PCB 데이터셋(693장, 결함 6종: open, short, mouse bite, spur, missing hole, spurious copper)을 대상으로 YOLOv8s/m 기반 결함 검출을 수행하였다. 결함 부위를 카테고리별로 분리한 뒤 GAN과 Diffusion으로 결함 패치를 생성하고, 원본 라벨 위치에 재배치하여 증강 데이터를 구성하였다(최적 증강 비율 30%). 실험에서는 Diffusion이 mAP에서 우위를 보였으며, GAN은 과적합이 상대적으로 낮아 실활용 측면의 가능성을 보였다. 다만 원본 라벨 위치를 재활용하는 방식은 기존 데이터와 배치 위치가 중복될 수 있다. 이러한 배치 위치의 다양성 한계가 제4장 연구의 출발점이 된다.

### 수식

| 번호 | 수식 | 설명 |
|---|---|---|
| (1) | $\min_G \max_D V(D,G)$ | GAN 적대적 목표. 생성자 G는 V 최소화, 판별자 D는 최대화 |
| (2) | $V(D,G) = \mathbb{E}_{x\sim p_{data}}[\log D(x)] + \mathbb{E}_{z\sim p_z}[\log(1-D(G(z)))]$ | GAN 가치함수. G가 실제 분포를 근사하도록 학습 |
| (3) | $q(X_t \mid X_{t-1})$ | Diffusion 순방향. 정규분포 노이즈를 점진적으로 추가 |
| (4) | $p_\theta(X_{t-1} \mid X_t) \cong q(X_{t-1} \mid X_t)$ | Diffusion 역방향. U-Net이 노이즈를 예측·제거해 원 분포 복원 |
| (5) | $P = \dfrac{TP}{TP+FP}$ | 정밀도. 검출한 것 중 실제 결함 비율 |
| (6) | $R = \dfrac{TP}{TP+FN}$ | 재현율. 실제 결함 중 검출한 비율 |
| (7) | $AP = \int_0^1 P(R)\,dR$ | 클래스별 PR 곡선 아래 면적 |
| (8) | $mAP = \dfrac{1}{N}\sum_{i=1}^{N} AP_i$ | 전 클래스 AP 평균, N = 클래스 수 |

### 처리 흐름

```text
PKU-HRI PCB_DATASET (693장, 6결함) ──► 카테고리별 결함 패치 분리
                                              ▼
                        GAN (1)(2)  /  Diffusion (3)(4) 로 결함 패치 생성
                                              ▼
                   원본 라벨 위치에 재배치 → 증강셋 972장 (30% 증강, 9:1 분할)
                                              ▼
                            YOLOv8s / YOLOv8m 학습 (Basic / GAN / Diffusion)
                                              ▼
                 P / R / mAP50 / mAP50-95 (5)~(8) + box loss 과적합 gap 분석
```

### 핵심 메시지

생성형 데이터 증강을 통해 결함 검출 성능을 향상시킬 수 있음을 확인하였다. 그러나 생성된 결함 패치의 배치 위치를 충분히 고려하지 않으면 기존 데이터와의 중복 및 과적합 문제가 남을 수 있다.

## 2. 제4장 — 결함검출 모델 성능 개선을 위한 결함데이터 증강

### 요약

제3장에서 확인한 결함 패치 배치 위치의 한계를 개선하기 위해, KolektorSDD(결함 52장)를 대상으로 ControlNet 기반 결함 생성, 유효 ROI 탐색, Poisson blending을 결합한 3단계 증강 방법을 제안하였다. 먼저 결함 마스크를 조건으로 결함 패치를 생성하고, 결함 주변 배경의 평균 밝기와 유사한 정상 영역을 탐색한 후 Poisson blending으로 결함을 삽입하였다. ResNet34 기반 실험에서 mIoU는 0.5667에서 0.8919로 향상되었다(증강 비율 0.5). 다만 배치 위치를 평균 밝기만으로 선정하기 때문에 배경 텍스처와 결함 주변의 구조적 특성을 충분히 반영하지 못한다. 이러한 한계를 개선하기 위해 제5장에서는 결함 형태와 배경 문맥의 관계를 데이터 기반으로 분석하는 방법을 제안한다.

### 수식

| 번호 | 수식 | 설명 |
|---|---|---|
| (1) | $X_t = D(\mathrm{concat}(x_{t+1}, C),\ t)$ | ControlNet 조건부 디노이징. x_t = t시점 잠재공간, D = Diffusion U-Net, C = 조건(결함 마스크), t = 노이즈 step. C를 U-Net 중간 레이어에 결합 |
| (2) | $C_{src} = \mathrm{mean}\big(I_{def}\cdot(M_{dilated} - M_{def})\big)$ | 결함 주변 배경 밝기. 마스크를 원형 팽창한 뒤 원 마스크를 빼 결함 둘레 고리만 남기고 평균 휘도 산출 |
| (3) | $\mathrm{Score}_i = \lvert C_{src} - C_{tgt,i}\rvert$ | 정상 이미지 후보 패치 i(128×128, stride 32 슬라이딩)의 평균 밝기와의 차. 최소 상위 k개 중 무작위 1개 → 유효 ROI |

식 (2)에서 사용한 결함 주변의 고리 영역은 제5장 site_score의 ring 히스토그램으로 이어진다. 다만 제4장은 주변 영역의 평균 밝기라는 단일 값을 사용하고, 제5장은 주변 영역의 문맥 셀 분포를 비교한다.

### 처리 흐름

```text
KolektorSDD 결함 마스크 ──► ControlNet 학습 (SD v1.5, 512², DDPM, 50 ep)
                                   ▼
                     결함 패치 생성  X_t = D(concat(x_{t+1}, C), t)   (1)
                                   ▼
결함 이미지 + 팽창 마스크 ──► 주변 밝기 C_src   (2)
                                   ▼
정상 이미지 슬라이딩 윈도우 (128×128 / 32px) ──► Score_i 최소 top-k → 무작위 1  (3)
                                   ▼
                    Poisson blending 삽입 → 증강셋
                                   ▼
      ResNet34 / EfficientNet 학습 (증강 비율 0.3 / 0.5 / 0.7) → mIoU · Dice
```

### 핵심 메시지

결함 주변 배경과 밝기 특성이 유사한 영역에 결함 패치를 배치함으로써 검출 성능을 향상시킬 수 있음을 확인하였다. 그러나 평균 밝기라는 단일 기준만으로는 다양한 배경 텍스처와 구조적 특성을 충분히 반영하기 어렵다.

## 3. 제5장 — AROMA: 적응형 ROI 기반 형태 인지 증강

### 요약

제4장에서 제기된 평균 밝기 중심의 배치 위치 탐색 한계를 개선하기 위해, 결함 형태와 배경 문맥 간 호환성을 데이터로부터 자동 도출하는 copy-paste 증강 프레임워크 AROMA를 제안하였다. 결함 형태(MCI)와 배경 문맥(CCI)을 프로파일링하고, 패치 단위 공동출현 통계를 바탕으로 대칭 호환성 게이트를 구성한다. 이를 통해 어떤 결함 패치를 선택할지, 어느 배경 이미지에 배치할지, 해당 배경의 어느 위치에 삽입할지를 순차적으로 결정한다. 생성 모델 자체의 품질과 배치 효과를 분리하여 평가하기 위해 training-free copy-paste 엔진을 사용하였다. AITeX, Kolektor, Severstal, MTD, MVTec Leather 등 5개 이종 데이터셋에 별도의 재설계 없이 적용하였다.

### 수식

| 번호 | 수식 | 설명 |
|---|---|---|
| (1) | $CCI = \mathrm{Mean}(\text{TextureEntropy},\ \text{ContextClusterCount},\ \text{FreqComplexity},\ \text{OrientVariance})$ | 배경 문맥의 복잡도를 나타내는 데이터셋 단위 지표. 4개 성분을 min-max 정규화한 뒤 동일 가중 평균으로 산출하며, 값이 높을수록 문맥 기반 배치 효과가 나타날 여지가 크다. |
| — | $MCI = \mathrm{Mean}(\text{Entropy},\ \text{ValleyCount},\ \text{ClassDiversity},\ 1-\text{Silhouette})$ | 결함 형태의 복잡도를 나타내는 데이터셋 단위 지표. CCI와 대칭적인 구조로, 4개 성분을 min-max 정규화한 뒤 동일 가중 평균으로 산출한다. |
| — | $K^{*} = \arg\min_k \mathrm{BIC}(k)$ | 결함 형태 클러스터 개수 자동 결정(GMM + BIC, BIC는 낮을수록 좋음). 수동 임계값 불필요 |
| (2) | $\mathrm{ctx\_prior}(k,c) \propto \sqrt{P_{def}(k,c)\cdot P_{clean}(c)}$ | **핵심**. 결함 형태 클러스터 k와 배경 문맥 셀 c 간 대칭 호환성을 나타낸다. 결함 주변에서 관측되고(P_def) 정상 이미지에도 존재하는(P_clean) 셀에 높은 점수를 부여하며, 기하평균을 사용해 한쪽 분포만 높은 후보의 점수를 억제한다. |
| (3) | $\mathrm{ROI\_score} = \mathrm{ctx\_prior} + \mathrm{morph\_prior}$ | 결함 패치의 우선순위를 산출한다. morph_prior는 클러스터 사전확률 P(k) = n_k/N이며, 점수에 따라 상위 K개를 선택한다. |
| (4) | $\cap(a,b) = \sum_c \min(a(c),\,b(c))$ | 히스토그램 교집합. 아래 두 점수의 기본 연산 |
| (5) | $\mathrm{bg\_score} = \mathrm{src\_fit} + \mathrm{class\_fit} + \mathrm{size\_fit}$ | 결함 패치에 적합한 배경 이미지를 선정한다. 원본 주변 분포, 클래스 프로파일 및 패치 크기 적합도를 함께 고려한다. |
| (6) | $\mathrm{site\_score} = \cap(h_s,\ \mathrm{tgt}[k])$ | 배경 이미지 내부의 삽입 위치를 선정한다. 후보 위치 s의 ring 히스토그램 h_s와 결함 형태 클러스터 k의 목표 문맥 분포 간 교집합이 최대인 위치를 선택한다. |

### 수식 상세 ① 배경 특징 — 배경 문맥 특징 5종과 CCI (식 1)

정상 이미지를 64px 격자로 자르고(결함 마스크 과반 패치 제외) 각 grayscale 패치 p에서 5개 값을 뽑는다. 이 5개 값의 P33/P66 삼분위 조합이 문맥 셀 키(예 `"2_2_1_2_0"`, 최대 3⁵ = 243개)가 되고, 같은 값을 집계한 것이 CCI 성분이다.

먼저 공통 도구 하나만 정의한다. **엔트로피 H(히스토그램)** = −Σ q·log₂q. 값이 여러 칸에 고르게 퍼져 있으면 크고, 한 칸에 몰려 있으면 작다. "얼마나 뒤섞여 있나"를 재는 자다.

| # | 특징 | 수식 | 한 줄 설명 | 낮으면 / 높으면 |
|---|---|---|---|---|
| 1 | 밝기 분산 (local_variance) | $\mathrm{Var}(p) = \dfrac{1}{N}\sum_i (x_i - \bar{x})^2$ | 패치 안 밝기가 얼마나 들쭉날쭉한가 | 매끈한 면 / 얼룩·요철 많은 면 |
| 2 | 엣지 밀도 (edge_density) | $\dfrac{1}{N}\sum_i \lvert\nabla p_i\rvert,\ \ \lvert\nabla p_i\rvert = \sqrt{S_x^2 + S_y^2}$ | 밝기가 급변하는 경계가 얼마나 많은가. 픽셀별 경계 세기의 평균 | 경계 거의 없음 / 선·무늬 많음 |
| 3 | 텍스처 엔트로피 (texture_entropy) | $H = -\sum_{k=1}^{10} q_k \log_2 q_k,\ \ q_k = $ LBP 패턴 k의 비율 | 미세 무늬 종류가 얼마나 다양한가 | 단조로운 결 / 여러 무늬 혼재 |
| 4 | 고주파 비율 (frequency_energy) | $\dfrac{\sum_{r > r_0} \lvert F(u,v)\rvert}{\sum \lvert F(u,v)\rvert},\ \ F = \mathrm{FFT}(p),\ r_0 = \min(h,w)/4$ | 주파수 스펙트럼에서 중심(저주파)으로부터 먼 성분이 차지하는 비중 | 완만한 변화 위주 / 잔결·노이즈 많음 |
| 5 | 방향 엔트로피 (orientation_consistency) | $H = -\sum_{b=1}^{18} q_b \log_2 q_b,\ \ q_b = \dfrac{\lvert\{i : \theta_i \in b\}\rvert}{N}$ | 경계들이 한 방향으로 정렬돼 있나. 방향 θ를 −180°~180° 18칸으로 나눈 픽셀 비율 | 줄무늬처럼 한 방향 / 방향이 제각각 |

설명 흐름: 1·2는 **"얼마나 거친가"**(밝기·경계의 양), 3·4는 **"어떤 결인가"**(무늬 종류·세밀함), 5는 **"어느 방향인가"**(정렬 정도). 5번은 이름이 consistency지만 엔트로피라서 **낮을수록 방향이 일관**됨에 주의.

세부 설정(질문 시): S_x, S_y는 Sobel 3×3 가로·세로 미분, N은 패치 픽셀 수. LBP는 주변 8픽셀(반경 1)을 중심과 비교한 회전불변 패턴 10종. F는 저주파가 중심에 오도록 정렬(fftshift)한 2D FFT, r은 스펙트럼 중심까지의 거리. θ = atan2(S_y, S_x)이며 부호를 살려 세고 경계 세기 가중은 하지 않는다(표 3의 경계 방향 엔트로피와 다른 점).

**CCI 4성분 — 5특징을 데이터셋 단위로 집계** (데이터셋당 20,000 패치 표본)

| CCI 성분 | 원료 | 집계 | 의미 |
|---|---|---|---|
| TextureEntropy | texture_entropy | 패치 **평균** | 텍스처 무질서도 |
| ContextClusterCount | 5특징 z-score 벡터 | GMM(k = 1..5) BIC 최적 k | 배경 문맥 군집 수 |
| FreqComplexity | frequency_energy | 패치간 **분산** | 주파수 특성의 이질성 |
| OrientVariance | orientation_consistency | 패치간 **분산** | 방향 특성의 이질성 |

TextureEntropy만 평균이고 Freq·Orient는 분산이다. 즉 "고주파가 많다·방향이 흐트러졌다"가 아니라 **패치마다 그 값이 얼마나 들쭉날쭉한가(배경 이질성)**를 잰다.

### 수식 상세 ② 배경 특징 — 텍스처 범주 (표 3, 해석·보고용)

위에서부터 첫 매치가 이긴다. 임계값은 패치 디스크립터 분포 관찰에 근거해 정한 고정값으로, 데이터셋마다 판정 기준이 흔들리지 않도록 범위를 고정했다. 범주 라벨은 해석·보고용이며 핵심 배치 경로(식 2~6)에는 쓰이지 않는다.

- Smooth: LocalVariance < 100.0
- Directional: GradOrientEntropy < 1.0
- Periodic: AutocorrPeak > 0.15
- Organic: LBPEntropy > 2.5
- Complex: 그 외

엔트로피 H는 위 5특징에서 정의한 것과 같은 자("얼마나 뒤섞여 있나")를 쓴다.

| 순서 | 디스크립터 | 수식 | 한 줄 설명 | 판정 |
|---|---|---|---|---|
| 1 | 밝기 분산 (LocalVariance) | $\mathrm{Var}(p) = \dfrac{1}{N}\sum_i (x_i - \bar{x})^2$ | 패치 안 밝기가 얼마나 들쭉날쭉한가 | < 100 → Smooth |
| 2 | 경계 방향 엔트로피 (GradOrientEntropy) | $H = -\sum_{b=1}^{8} q_b \log_2 q_b,\ \ q_b = \dfrac{\sum_{i \in b} \lvert\nabla p_i\rvert}{\sum_i \lvert\nabla p_i\rvert}$ | 뚜렷한 경계들이 한 방향으로 정렬돼 있나. 방향 θ를 0~180° 8칸으로 나누고 경계 세기로 가중 | < 1.0 → Directional |
| 3 | 자기상관 피크 (AutocorrPeak) | $\max_{(u,v)\neq(0,0)} \dfrac{R(u,v)}{R(0,0)},\ \ R(u,v) = \sum_x p(x)\,p(x+(u,v))$ | 패치를 (u, v)만큼 밀어 겹쳤을 때 원래와 얼마나 닮나. R(0,0)은 자기 자신과의 겹침 | > 0.15 → Periodic |
| 4 | 텍스처 엔트로피 (LBPEntropy) | $H = -\sum_{k=1}^{10} q_k \log_2 q_k,\ \ q_k = $ LBP 패턴 k의 비율 | 미세 무늬 종류가 얼마나 다양한가 | > 2.5 → Organic |
| — | — | — | 위 어디에도 해당하지 않음 | → Complex |

설명 흐름: 위에서부터 차례로 묻는다. **"매끈한가?"** → **"한 방향 결인가?"** → **"반복 무늬인가?"** → **"여러 무늬가 섞였나?"** → 모두 아니면 Complex. 먼저 맞는 질문에서 범주가 정해진다.

세부 설정(질문 시): ∇p는 Sobel 3×3, θ = atan2(Sy, Sx) mod 180°(부호 무시)를 22.5° 간격 8칸으로 나눈다. 자기상관 R은 실제 계산에서 R = ℱ⁻¹(\|ℱ(p)\|²)(Wiener–Khinchin 정리)로 FFT를 이용해 한 번에 구하며, 위의 합 정의(패치 경계에서는 반대편으로 순환 이동)와 같은 값이다. LBP는 주변 8픽셀(반경 1)을 중심과 비교한 회전불변 패턴 10종.

이름 주의: 표 3 디스크립터는 이름이 비슷한 5특징·CCI 성분과 다른 양이다. LBPEntropy는 texture_entropy와 같은 식이지만 패치 값 그대로 쓴다(CCI는 평균). AutocorrPeak는 반복성을 재고, FreqComplexity는 고주파 비율의 분산이다. 경계 방향 엔트로피는 부호를 접은 8칸·크기 가중이고, 5특징의 방향 엔트로피는 부호를 살린 18칸·비가중이다.

### 수식 상세 ③ 결함 특징 — 형태 특징 6종, 군집 K*, MCI

결함 이미지 1장의 마스크(GT 우선, 없으면 SAM → Otsu 폴백)에서 **8-연결 성분 중 최대 면적 blob 1개**를 골라 6개 형태 특징을 잰다. 이 6종이 군집 K*와 MCI의 공통 원료다(배경 쪽 ①의 5특징에 대응).

| # | 특징 | 수식 | 한 줄 설명 | 낮으면 / 높으면 |
|---|---|---|---|---|
| 1 | 선형성 (linearity) | $1 - \dfrac{\lambda_{min}}{\lambda_{max}}$, λ = 픽셀 좌표 2×2 공분산 고유값 | 결함이 한 방향으로 얼마나 뻗었나 | 원형 / 선형 |
| 2 | 견고도 (solidity) | $\dfrac{A}{A_{convex\_hull}}$ | 볼록껍질(고무줄로 감싼 영역)을 얼마나 채우나 | 요철·오목·가지형 / 꽉 찬 볼록 |
| 3 | 면적비 (extent) | $\dfrac{A}{A_{bbox}}$ | 외접 사각형을 얼마나 채우나 | 대각선·흩어진 모양 / 사각형에 가까움 |
| 4 | 종횡비 (aspect_ratio) | $\alpha = \dfrac{\text{major}}{\text{minor}} = \sqrt{\dfrac{\lambda_{max}}{\lambda_{min}}}$ (2차 중심모멘트 등가 타원) | 등가 타원이 얼마나 길쭉한가 | 1 = 원 / 가늘고 긺(롱테일) |
| 5 | 이심률 (eccentricity) | $\sqrt{1 - (\text{minor}/\text{major})^2}$ | 등가 타원이 원에서 얼마나 벗어났나 | 원 / 선분 |
| 6 | 원형도 (circularity) | $\dfrac{4\pi A}{P^2}$, P = 둘레 | 둘레 대비 면적이 원에 얼마나 가까운가 | 들쭉날쭉한 경계 / 1 = 원 |

설명 흐름: 1·4·5는 **"얼마나 긴가"**, 2·3은 **"얼마나 꽉 찼나"**, 6은 **"경계가 얼마나 매끈한가"**.

독립 축이 아니다: 1·4·5는 같은 등가 타원의 함수로 linearity = 1 − 1/α², eccentricity = √linearity가 정확히 성립한다(Spearman 1.000). 실질 자유도는 4축(세장·solidity·extent·circularity).

**군집 K\*** (결함 형태 군집 = 호환성 게이트의 **행**)

```text
X ∈ ℝ^(N×6) → 특징별 min-max [0,1] → GaussianMixture(k = 1..5) → K* = argmin BIC
```

- BIC = 적합도와 모형 복잡도를 함께 본 점수로, 낮을수록 좋다. 군집 개수와 경계가 모두 데이터에서 정해진다
- 군집 k는 morph_prior P(k) = n_k / N(식 3)와 호환성 행렬(식 2)의 행 인덱스로 쓰인다
- 배경 쪽 ContextClusterCount는 z-score, 여기는 min-max로 정규화 방식이 다르다

**MCI 4성분 — 형태 특징을 데이터셋 단위로 집계** (CCI와 대칭 구조)

| MCI 성분 | 수식 | 원료 | 의미 |
|---|---|---|---|
| Entropy | $-\sum_k p_k \log_2 p_k$ | 군집 라벨 분포 | 군집 크기가 얼마나 고르게 나뉘나 |
| ValleyCount | 6특징 각 분포의 골짜기 수 합 | 6특징 히스토그램 | 분포가 몇 갈래로 나뉘나(다봉성) |
| ClassDiversity | $N_{eff} = \exp\!\left(-\sum_c p_c \ln p_c\right)$ (Hill 수) | GT 결함 클래스 라벨 | 결함 종류의 실효 개수 |
| 1 − Silhouette | 1 − silhouette(X, 라벨) | 6특징 + 군집 라벨 | 군집이 잘 안 갈릴수록 큼 → 복잡 |

**결함 하위유형** (표 4, 6특징 중 α·σ 2개만 사용, GMM 군집과 별개 경로)

설명 흐름: α는 **"얼마나 긴가"**, σ는 **"얼마나 꽉 찼나"**. 길면 scratch, 짧고 꽉 찼으면 blob, 꽉 차지 않았으면 irregular. 6장 CASDA와 같은 이름의 지표를 쓰되, 임계값을 고정 상수 대신 데이터셋별 분포(P33/P66)에서 정한다는 점이 차이.

### 수식 상세 ④ 결합·선택 — 대칭 호환성 게이트와 선택 3단계 (식 2~6)

**식 (2) 대칭 호환성 게이트**: 행 k = 결함 형태 군집(③), 열 c = 배경 문맥 셀(①). 두 번의 집계로 만든다. P_def(k, c)는 군집 k 결함 둘레 타일 중 셀 c의 비율, P_clean(c)는 정상 이미지 전체 타일 중 셀 c의 비율이다. 둘을 기하평균(√곱)으로 AND 결합하므로 "결함 주변에서 실제로 관측되고, 정상 이미지에도 충분히 존재하는" 셀만 높은 점수를 받는다. 결과는 행 최댓값 = 1로 저장한 `matrix_symmetric`이다.

논문 식 (3)·(5)·(6)은 "어떤 결함 → 어느 배경 이미지 → 그 안의 어느 자리"의 3단 선택 체인이다. 공통 재료는 프로파일링 산출물 하나(`matrix_symmetric`)이고, 픽셀은 다시 보지 않는다.

**① 어떤 결함을 쓸까** (`roi_selection.py`)

```text
ROI_score = ctx_prior + morph_prior                 (식 3)
```

- ctx_prior = `matrix_symmetric[k][cell_key]` — 결함 자신의 소스 문맥 셀에서 읽은 스칼라
- morph_prior = P(k) = n_k / N
- 선발 규칙: (k,c) pair quota + 클래스 floor + 소스 크롭 1회 사용 → top_k (Severstal 1000 / 나머지 200)

**② 어느 배경 이미지에 붙일까** (`clean_bg_selection.py`)

```text
∩(a,b) = Σ_c min(a_c, b_c)                      히스토그램 교집합 (식 4)

src_fit   = ∩(h_g, p_src)     결함이 원래 살던 이미지의 표면과 닮았나   (개체 단위)
class_fit = ∩(h_g, p_cls)     이 클래스 결함들의 배경 집계와 닮았나     (클래스 단위)
size_fit  = min(1, 0.95·W/w, 0.95·H/h)   왜곡 없이 들어가나             (기하)

bg_score  = src_fit + class_fit + size_fit      (식 5)
```

- 필터가 아니라 랭킹. void 게이트(P15 분산·엣지, 과반-void 컷)로 거른 뒤 bg_score 상위 배경을 배정
- 이미지 선택은 전역, 자리 선택은 국소. 결함 인접 타일로 국소화한 대안은 self-retrieval MRR에서 5/5 열세

**③ 그 배경의 어느 자리에 붙일까** (`ring_sgm`)

```text
tgt[k]     = L1norm(matrix_symmetric[k])          군집 k의 목표 문맥 분포
h_s(c)     = 자리 s를 둘러싼 ring R(s) 타일들의 셀 정규화 히스토그램 (void 제외)
score(k,s) = ∩(h_s, tgt[k])                       (식 6)
s*         = argmax_{valid s} score(k,s)
valid(s)  ⟺ ∀t∈F(s): observed ∧ ¬void          footprint 전 타일 admissible
```

- tgt[k] 도출 4단계: ① 인구조사 2번(P_def(k,·) = 군집 k 결함 둘레 타일, P_clean = clean 전 타일) → ② AND 결합 √곱(식 2) → ③ 행 max=1 저장(히트맵) → ④ 사용 직전 합=1 재정규화. ③→④는 단조 rescale이라 모양 불변
- 왜 ring인가: footprint는 결함이 덮어 사라진다. 합성 후 경계 연속성을 결정하는 것은 둘레
- 왜 분포 매칭인가(평균 ✗): 평균 argmax는 "흔한 셀이 많은 자리"로 수렴. min-겹침은 초과분을 잘라 흔한-셀 몰빵을 차단. footprint→ring(평균 유지)은 4/5 악화, 평균→분포 매칭은 5/5 개선 — 개선의 원천은 score 정의
- 성질: ∩(a,b) = 1 − TV(a,b). 교집합 최대화 ≡ total variation 거리 최소화

**한 줄 암기**: 지도 1개(`matrix_symmetric`) ← 이미지가 h_g로, 자리가 h_s로 질의. 결함(①) → 배경(②, 전역) → 자리(③, 국소).

### 핵심 메시지

AROMA의 증강 효과는 기존 검출 모델의 성능 개선 여지(baseline headroom)와 배경 문맥의 복잡도(CCI)가 함께 작용할 때 두드러진다. 이러한 조건이 충분하지 않은 경우에는 Random-ROI 방식과 유사한 성능을 보였으며, 증강으로 인한 성능 저하도 나타나지 않았다.

이는 형태·문맥 호환성 분석이 모든 데이터셋에서 일률적인 성능 향상을 보장하기보다, 데이터셋의 특성과 기존 검출 성능에 따라 효과를 발휘한다는 점을 보여준다. 이처럼 배치 단계의 문맥 자동화를 확립한 뒤, 제6장에서는 철강 도메인에 특화된 규칙을 적용하고 문맥 정보를 결함 생성 조건까지 확장한다.

- 검출기 교체 재현(YOLOv11n): Severstal에서 AROMA−Random이 +1.48 pp(3/3 seed)를 보였다. 이는 관찰된 효과가 특정 검출기 하나에만 국한되지 않음을 보완적으로 보여준다.
- 선택 분포 균등도(정규화 엔트로피·Gini): 5개 데이터셋 중 4개에서 AROMA가 Random 이상을 보였다. AITeX에서는 선택 분포의 균등도보다 호환성을 우선하는 양상이 나타났다.

## 4. 제6장 — CASDA: 문맥 인지 강철 결함 증강

### 요약

제5장에서 제안한 결함 형태와 배경 문맥 간 호환성 개념을 철강(Severstal) 도메인에 특화하고, 문맥 정보를 결함 배치뿐 아니라 **생성 단계까지 확장**한 CASDA 프레임워크를 제안하였다. 먼저 결함의 기하학적 특성을 기반으로 결함 형태를 분류하고, Canny 및 Sobel 특성을 활용하여 배경 유형을 구분한다. 이후 형태와 배경 유형 간 호환성 행렬을 구성하여 적합한 배경을 선택한다. 선정된 배경의 문맥 정보는 3채널 힌트 이미지와 4개 필드의 문맥 프롬프트로 구성하여 ControlNet의 조건으로 활용한다. 생성된 결함은 Poisson blending으로 배경에 합성하고, 품질 게이트(Q ≥ 0.7)를 적용하여 증강 데이터의 품질을 관리한다. EB-YOLOv8에서 Copy-Paste 대비 mAP@0.5가 +2.60 pp, Class 2 AP가 +22.09 pp 개선되었다. 다만 YOLO-MFD에서는 개선이 나타나지 않아, 증강 효과가 검출 모델 아키텍처에 따라 달라질 수 있음을 확인하였다.

### 수식

| 번호 | 수식 | 설명 |
|---|---|---|
| (1) | $\lambda = 1 - \dfrac{\lambda_{min}}{\lambda_{max}}$ | 선형성. 1에 가까울수록 선형(스크래치). 5장 linearity와 같은 식 |
| (2) | $\sigma = \dfrac{A_{defect}}{A_{convex\_hull}}$ | 견고도(solidity). 낮으면 경계 불규칙 |
| (3) | $\varepsilon = \dfrac{A_{defect}}{A_{bounding\_box}}$ | 면적비(extent). 직사각형성 |
| (4) | $\alpha = \dfrac{\text{major axis}}{\text{minor axis}}$ | 종횡비. 최소자승 타원 적합 |
| (5) | $S_{suitability} = 0.5\,S_{matching} + 0.3\,S_{continuity} + 0.2\,S_{stability}$ | ROI 적합도. 매칭 품질·공간 연속성·배경 안정성 가중합. 평균 0.68, ≥ 0.7 고품질군 61.3% |
| (6) | prompt = "F1 on F2 with F3 (F4), Class N" | 문맥 프롬프트. F1 결함유형 · F2 배경표면 · F3 방향성 텍스처 · F4 안정성 점수 s → pristine(s ≥ 0.8) / standard(0.5 ≤ s < 0.8) / worn(s < 0.5) |
| 표 2 | $\text{hint} = 0.5R + 0.3G + 0.2B$ | ControlNet 3채널 힌트 이미지. 채널 구성은 아래 표 2 |
| 표 7 | $Q = 0.3\,Q_{morph} + 0.3\,Q_{sharp} + 0.2\,Q_{artifact} + 0.2\,Q_{area}$ | 품질 점수. Q ≥ 0.7만 채택. 성분 기준은 아래 표 7 |
| §4.3 | $\mathrm{BGD} = \mathrm{mean}_{p\in B}\,\lvert\nabla I\rvert,\ \ B = \mathrm{dilate}(M,5) - \mathrm{erode}(M,5)$ | 경계 기울기 불연속(평가 지표). 합성 경계 밴드의 평균 Sobel 크기. CASDA 49.6 vs Copy-Paste 71.4 (−30.5%, Cohen's d ≈ 0.87) |

표 2·표 7·§4.3의 수식은 논문에서 본문 식 번호 없이 표와 절 안에 정의되어 있어 위치를 번호 대신 적었다.

### 수식 상세 ① 배경 특징 — 표면 지표와 배경 5유형

64px 격자 패치마다 표면 지표를 구하고, 고정 임계값으로 배경 5유형(호환성 행렬의 **열**)을 정한다. 5장 "배경 문맥 특징 5종"에 대응한다.

| 특징 | 산출 | 설명 | 낮으면 / 높으면 |
|---|---|---|---|
| 밝기 분산 | $\mathrm{Var}(p) = \dfrac{1}{N}\sum_i (x_i - \bar{x})^2$ | 패치 안 밝기가 얼마나 들쭉날쭉한가 | 매끈한 면 / 거친 면 |
| 엣지 밀도 | Canny 엣지 검출 결과의 엣지 픽셀 비율 | 경계가 얼마나 많은가 | 경계 거의 없음 / 무늬·요철 많음 |
| 방향 비율 (x_ratio, y_ratio) | Sobel_x / Sobel_y 응답이 전체 그라디언트에서 차지하는 비율 | 결이 세로 방향인지 가로 방향인지 | 방향성 약함 / 한 방향 줄무늬 |

**배경 5유형 분류** (위에서부터 첫 매치)

| 배경 유형 | 조건 | 표면 |
|---|---|---|
| Smooth | 분산 < 200 ∧ 엣지 < 0.02 | 매끈한 무지 표면 |
| V-Stripe | x_ratio > 0.65 ∧ 엣지 > 0.02 | 세로 줄무늬 |
| H-Stripe | y_ratio > 0.65 ∧ 엣지 > 0.02 | 가로 줄무늬 |
| Complex | 엣지 > 0.15 | 경계가 매우 많은 복잡 패턴 |
| Textured | 분산 > 500 ∨ 엣지 > 0.05 | 거친 질감 |

**배경 적합도 임계값** (clean 배경 패치 분포에서 log-scale Otsu)

| 지표 | 임계값 | 의미 |
|---|---|---|
| 분산 τ | 14.09 | 이하인 저분산 배경만 선택 |
| 엣지 밀도 | 0.607 | 이하인 저엣지 배경만 선택 → 도메인 불일치(BGD) 감소 |

엣지 밀도 임계값은 논문에서 ε로 표기되지만, 식 (3)의 면적비 ε와 기호가 겹치므로 발표 시 구분해 부른다.

### 수식 상세 ② 결함 특징 — 기하 4지표와 결함 4유형 (식 1~4, 표 1)

결함 마스크에서 기하 4지표를 구하고, 고정 임계값으로 결함 4유형(호환성 행렬의 **행**)을 정한다. 5장 "결함 하위유형"에 대응한다.

| 기호 | 수식 | 설명 |
|---|---|---|
| λ | $\lambda = 1 - \dfrac{\lambda_{min}}{\lambda_{max}}$ (식 1) | 선형성. 마스크 픽셀 좌표 2×2 공분산의 고유값으로 산출(5장 linearity와 같은 식). 1에 가까울수록 한 방향으로 뻗은 선형(스크래치) |
| σ | $\sigma = \dfrac{A_{defect}}{A_{convex\_hull}}$ (식 2) | 견고도(solidity). 볼록껍질 대비 실제 면적. 1에 가까울수록 꽉 찬 덩어리, 낮으면 경계 불규칙 |
| ε | $\varepsilon = \dfrac{A_{defect}}{A_{bounding\_box}}$ (식 3) | 면적비(extent). 외접 사각형 대비 실제 면적. 1에 가까울수록 직사각형에 가까움 |
| α | $\alpha = \dfrac{\text{major axis}}{\text{minor axis}}$ (식 4) | 종횡비. 최소자승 타원 적합의 장축/단축. 클수록 가늘고 긺 |

설명 흐름: λ·α는 **"얼마나 길게 뻗었나"**, σ·ε는 **"얼마나 꽉 찼나"**. 이 4지표를 고정 임계값으로 잘라 4유형을 만든다(5장 AROMA는 같은 α·σ를 데이터셋별 P33/P66으로 자름).

**표 1. 결함 4유형 분류 기준** (N = 19,958 분포에서 도출: 고경계 λ = 0.85, σ = 0.9는 log-scale Otsu, 저경계는 백분위)

| 유형 | 조건 | 형태 |
|---|---|---|
| linear_scratch | λ > 0.85 ∧ α > 5.0 | 가늘고 곧은 선형 |
| irregular | σ < 0.7 | 경계가 들쭉날쭉한 불규칙형 |
| compact_blob | α < 2.0 ∧ σ > 0.9 | 둥글고 꽉 찬 덩어리 |
| general | 그 외 | 위에 해당하지 않는 일반형 |

### 수식 상세 ③ 결합·선택 — ROI 적합도와 호환성 행렬 (식 5, 표 6)

**식 (5) ROI 적합도**: S_suitability = 0.5·S_matching + 0.3·S_continuity + 0.2·S_stability. 결함–배경 매칭 품질, 공간 연속성, 배경 안정성의 가중합이다. 평균 0.68이며, 0.7 이상 고품질 61.3% / 사용 가능 31.5% / 제외 7.2%로 나뉜다.

**표 6. 호환성 행렬** (결함유형 × 배경유형 매칭 점수, 1.0 = 최적. 점수를 가중치로 배경을 확률 선택)

| Defect \ BG | Smooth | V-Stripe | H-Stripe | Textured | Complex |
|---|---|---|---|---|---|
| Linear scratch | 0.7 | 1.0 | 1.0 | 0.5 | 0.3 |
| Compact blob | 1.0 | 0.5 | 0.5 | 0.7 | 0.6 |
| Irregular | 0.6 | 0.5 | 0.5 | 0.8 | 1.0 |
| General | 0.7 | 0.7 | 0.7 | 0.7 | 0.7 |

- 셀 값은 결함유형 × 배경유형 매칭 점수이며, 행마다 최적 배경이 1.0이다. 배경은 이 점수를 가중치로 한 확률 추출로 고른다
- 통계는 결함 중심이 든 64px 셀 단위로 잡히지만, 적용은 이미지 1장 = 배경 라벨 1개 단위(이미지 선택)다. 이미지 안의 위치까지 고르는 것은 5장 AROMA의 설계

### 수식 상세 ④ 생성·품질 — 힌트·프롬프트, 품질 게이트, BGD (식 6, 표 2, 표 7, §4.3)

**표 2. 3채널 힌트 구성** (hint = 0.5R + 0.3G + 0.2B)

| 채널 | 가중 | 담는 정보 | 구성 규칙 |
|---|---|---|---|
| R | 0.5 | 결함 기하 | λ > 0.7 → skeleton + edge / σ > 0.8 → filled / 그 외 → edge |
| G | 0.3 | 배경 표면 방향 | V-stripe → Sobel_x / H-stripe → Sobel_y / Complex → 전방향(omni) / Smooth·Textured → 0 |
| B | 0.2 | 표면 거칠기 | 7×7 국소분산 (Smooth는 ×0.5) |

**식 (6) 문맥 프롬프트**: "F1 on F2 with F3 (F4), Class N". F1 결함유형(②), F2 배경표면(①), F3 방향성 텍스처, F4 배경 안정성 점수 s에 따른 상태어 — pristine(s ≥ 0.8) / standard(0.5 ≤ s < 0.8) / worn(s < 0.5). 힌트가 "어떤 모양을 어디에", 프롬프트가 "어떤 표면 위의 무슨 결함인지"를 ControlNet에 알려준다. 생성된 결함은 Poisson blending(`cv2.seamlessClone`, 마스크 8px 팽창)으로 배경에 합성한다.

**표 7. 품질 게이트 성분** (Q = 0.3Q_morph + 0.3Q_sharp + 0.2Q_artifact + 0.2Q_area, Q ≥ 0.7 채택)

| 성분 | 가중 | 측정 대상 | 점수 기준 |
|---|---|---|---|
| Q_morph | 0.3 | 형태 일치 | 마스크 유형 일치 1.0 / general 0.7 / 불일치 0.3 |
| Q_sharp | 0.3 | 선명도 | Laplacian 분산 (< 100이면 블러) |
| Q_artifact | 0.2 | 노이즈·아티팩트 | 없음 1.0 / 10% 초과 0.0 |
| Q_area | 0.2 | 면적 적정성 | 면적 0.1~30% 1.0 / 그 외 0.5 |

**§4.3 BGD (평가 지표)**: BGD = mean_{p∈B} |∇I|, B = dilate(M, 5) − erode(M, 5). 합성 결함 경계를 따라 띠(B)를 만들고 그 안의 평균 Sobel 크기를 잰다. 경계가 자연스럽게 이어질수록 낮다. CASDA 49.6 vs Copy-Paste 71.4 (−30.5%, Cohen's d ≈ 0.87).

### 처리 흐름

```text
[1단계] 결함·배경 특성 분석 ── λ σ ε α (1)~(4) → 표 1 → 결함 4유형

                      ▼

                      ▼
[3단계] 문맥 기반 합성 ── 표 6 호환성 행렬로 배경 확률 선택 → ControlNet 생성 → Poisson blending
                      ▼
[4단계] 품질 게이트 ── Q (표 7) ≥ 0.7 → 2,500 중 2,075 통과 (83.0%)
                      ▼

                      ▼
```

### 핵심 메시지

문맥 정보를 결함 생성 조건(힌트 이미지·프롬프트)에 반영함으로써, 결함 배치뿐 아니라 생성 단계까지 문맥을 고려하는 증강 접근을 제시하였다. 특히 희소 클래스에서 성능 개선을 확인하였다. 다만 철강 결함에 특화된 분류 및 호환성 규칙을 사용하므로 다른 도메인에 적용할 때는 재설계가 필요하다. 따라서 CASDA는 범용 자동화보다는 특정 제조 도메인에서 생성 단계까지 문맥을 반영하는 접근으로 정리할 수 있다.
