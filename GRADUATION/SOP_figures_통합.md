## 3. 공통 규칙

### 3-1. 그림 번호 체계

- 학위논문 번호는 **장-일련번호**(`그림 3-1`, `그림 5-14`)를 따르며, **본문 등장 순서**로 부여한다.
- 게재 논문 원문의 그림 번호(`그림 1`, `Figure 4`)는 **원문 내 배치 순서**일 뿐이므로 학위논문 번호와 일치하지 않는다. 반드시 §5~§8 매핑 표를 근거로 치환한다.
- 원문 그림 여러 장이 학위논문 한 그림으로 합쳐지는 경우 `(a)/(b)` 패널로 표기하고 매핑 표 비고에 명시한다.

### 3-2. 이미지 파일 경로 규칙 (예약)

```
GRADUATION/figures/fig<장>-<번호>[<패널>].<확장자>
예: figures/fig3-1.jpg, figures/fig3-9a.jpg, figures/fig3-9b.jpg
```

- 확장자는 원본 media의 확장자를 그대로 유지한다(.jpg/.png).
- 이미지 파일 배치 전에도 본문에 마크다운 이미지 문법을 **미리 작성**해 둔다(파일이 없으면 렌더링만 깨지고 텍스트는 보존).

### 3-3. 본문 삽입 형식

```markdown
![그림 3-1](figures/fig3-1.jpg)

**그림 3-1.** (a) Short, (b) Spur, (c) Spurious copper, (d) Missing hole,
(e) Mouse bite, (f) Open circuit — PCB_DATASET 결함 유형 예시
```

- 캡션은 이미지 **아래**에 둔다(표 캡션은 표 위 — 기존 문서 관례 유지).
- **본문 참조 표기는 `(그림 3-7)` 형태로 통일한다.** 현 초안의 `(\[그림 3-7. 캡션\])` 형태는 대괄호 이스케이프·캡션 중복을 제거하고 번호만 남긴다. (결정 완료)

### 3-4. 본문 서술 작성 규칙

- 원문의 그림 설명 문단을 **발췌**하되 다음을 조정한다:
  - 그림 번호를 학위논문 번호로 치환.
  - 원문 "본 논문에서는" → "본 장에서는".
  - 영문 원문(AROMA·CASDA)은 학위논문 국문 문체로 번역·축약한다.
- 제2장 관련 연구로 이미 올라간 **일반 원리 설명은 중복 서술하지 않고** 2.x절 상호참조로 대체한다(`SOP_참고문헌_통합.md` §B-2와 동일 원칙).
- 그림 해설은 **그림이 보여주는 것 + 그것이 이 장의 주장에 왜 필요한지** 두 요소를 포함한다. 캡션 반복 금지.
- 원문에 해설이 없고 캡션만 있는 경우 임의 창작하지 않고, 본문 맥락에서 확인 가능한 사실만 1~2문장 기술한 뒤 §9 로그에 "원문 해설 없음"으로 남긴다.

## 4. 절차 (STEP)

### STEP 1 — 대상 장의 플레이스홀더 인벤토리
1. 본문에서 해당 장의 `\[그림 X-Y ...\]` 전수 추출. **개행으로 분할된 항목 누락 주의** — 개행을 공백으로 치환한 뒤 검색할 것.
2. 각 항목의 **본문 내 위치(줄 번호)** 와 **참조 문맥**을 기록한다.

### STEP 2 — 원문 그림 추출·매핑
1. docx의 `word/document.xml`을 문단 순서대로 훑어 `r:embed`/`r:link`/`r:id` 이미지 참조와 캡션 문단을 대응시킨다(이미지 문단의 직전 또는 직후 문단이 캡션).
2. `word/_rels/document.xml.rels`로 rId → `media/imageN.ext`를 해석한다.
3. 매핑 표(§5 형식)를 작성한다. 중간 산출물은 `.claude/.etc/figures/<장>_figure_map.md`에 보관한다.
4. 학위논문에 없는 원문 그림(저널 로고·저자 사진·수식 이미지)은 **제외** 열에 명기한다.

### STEP 3 — 캡션·본문 서술 작성
1. 플레이스홀더를 §3-3 형식의 이미지+캡션 블록으로 치환한다.
2. §3-4 규칙에 따라 그림 해설 문단을 배치하거나 기존 문단에 통합한다.
3. 본문 참조를 §3-3 규칙(`(그림 X-Y)`)으로 정리한다.

### STEP 4 — 상호참조 정합
- 본문 참조와 캡션 번호가 1:1 대응하는지 확인한다.
- 장 단위로 번호 결번·중복이 없는지 확인한다.

### STEP 5 — 이미지 파일 배치 (추후 단계)
- docx `word/media/`에서 대상 이미지를 추출해 §3-2 규칙으로 `GRADUATION/figures/`에 복사·개명한다. **복사·개명만 허용하며 크롭·합성·재렌더링은 하지 않는다.**
- 해상도·가독성이 미달하는 그림이 있으면 임의로 재생성하지 말고 §9 로그에 목록화해 사용자에게 보고한다.

### STEP 6 — 검증
- [ ] 해당 장의 `\[그림 ...\]` 플레이스홀더가 0건이다.
- [ ] 모든 그림이 `![...](...)` + `**그림 X-Y.** 캡션` 형식을 갖는다.
- [ ] 그림 번호가 `X-1`부터 결번·중복 없이 연속이다.
- [ ] 본문 참조가 모두 `(그림 X-Y)` 형태이고 캡션과 1:1 대응한다.
- [ ] 매핑 표의 모든 행이 본문에 반영되었고, 미사용 원문 그림이 사유와 함께 기록되었다.
- [ ] (STEP 5 수행 시) 참조된 모든 이미지 경로가 실제 파일로 존재한다.

## 10. 주의사항

- **그림 자체를 손대지 않는다.** 원문 이미지의 재작성·재생성·패널 재구성·크롭·색상 조정 금지. 학위논문과 범위가 어긋나면 캡션과 본문으로 맞춘다(§1 대원칙).
- **원문 수치·주장을 그림 해설에서 변형하지 않는다.** 본문과 그림 해설이 상충하면 수정하지 말고 로그에 기록 후 확인받는다(예: §5-2의 972 vs 826).
- 그림 번호는 **장 번호에 종속**된다. 향후 장 구성이 바뀌면 `SOP_참고문헌_통합.md` STEP R과 동일하게 **역순 일괄 치환**이 필요하다.
- 미대응 원문 그림을 추가 삽입하면 **후속 그림 번호가 밀린다.** 장별로 삽입 여부를 먼저 확정한 뒤 번호를 부여한다.
- 저작권·출처: 게재 논문 본인 저작물이므로 전재 가능하나, 각 장 도입부에 해당 게재 논문의 참조 번호(`\[54\]`, `\[55\]`, `\[56\]`, `\[31\]`)가 명시되어 있는지 확인한다.
- 작업은 장 단위로 커밋하는 것을 권장한다 (커밋은 사용자 요청 시에만).
