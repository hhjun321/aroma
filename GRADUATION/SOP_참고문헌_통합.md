- **원리 설명은 Related Work로, 본 연구에서의 사용 방식은 각 장에 남긴다.**

- 그림 중 원리 설명용 그림([그림 2-3. GAN 학습과정], [그림 2-5. Diffusion 학습과정])은 Related Work로 이동을 검토하되, 게재 논문 원문 보존이 우선이면 그대로 두고 상호참조만 추가한다 → **사용자 결정 필요 항목**.
- 데이터셋 개관(2.8절)은 표 1개로 통합(도메인·규모·클래스 수·사용 장)하고, 각 장의 상세 분할 표(표 3-1, 표 4-4 등)는 그대로 유지한다.
- Related Work는 단순 나열이 아니라 **본 연구와의 차별점**으로 끝맺는다: 기존 연구가 P1에 집중하고 P2를 수작업 규칙/무작위 배치에 맡겨온 공백 → 본 논문의 위치 명시.

## 4. 작업 축 C — 참고문헌 통합: 절차

### STEP 1 — 참고문헌 인벤토리 작성
1. 2.5 / 3.5 / 4.5 / 5.5의 모든 항목을 추출해 작업 표를 만든다.
   - 컬럼: `장`, `장내 번호`, `제1저자`, `연도`, `제목(축약)`, `DOI/URL`, `중복 그룹 ID`
2. 중간 산출물은 `.claude/.etc/` 하위에 보관한다 (예: `.claude/.etc/ref_merge/ref_inventory.md`).

### STEP 2 — 중복 판정 (Dedup 규칙)
- **동일 판정 기준(우선순위 순)**: ① DOI 일치 → ② 제1저자+연도+제목 일치 → ③ 제목만 일치하되 서지 정보가 상충하면 수동 확인.
- 동일 문헌인데 서지 표기가 장마다 다른 경우(예: 3장 [12] vs 4장 [6]의 Goodfellow — 페이지·표기 차이), **가장 완전한 서지 정보를 가진 버전**을 대표로 채택한다.
- 상충 사례(연도·권호가 다른 동일 제목 등)는 삭제하지 말고 SOP 실행 로그에 기록 후 사용자 확인을 받는다.
  - 알려진 예: Tabernik KolektorSDD가 3장에서는 2019, 4장에서는 2020으로 표기됨 → 정본 확인 필요 (DOI 10.1007/s10845-019-01476-x, 저널판 2020).

### STEP 3 — 통합 목록 정렬·번호 부여
- **정렬 원칙: 본문 등장 순서(order of first appearance)** — 제2장 → 제3장 → 제4장 → 제5장 순으로 처음 인용/수록된 순서대로 전역 번호를 부여한다.
  - 학교 양식이 저자명 알파벳순을 요구하면 이 단계에서만 정렬 방식을 교체하면 된다 (매핑 표 구조는 동일).
- 매핑 표 작성: `(장, 장내 번호) → 전역 번호`. 이 표가 STEP 4의 유일한 근거다.

### STEP 4 — 본문 인용 재매핑
1. 본문에서 `\[숫자\]` 패턴을 장별로 검색한다 (참고문헌 절 내부 제외).
2. 각 인용을 매핑 표에 따라 전역 번호로 치환한다. **장 경계를 넘는 일괄 치환 금지** — 같은 `[1]`이 장마다 다른 문헌이므로 반드시 장 단위로 치환한다.
3. 현재 문서는 본문 인용 표기가 거의 없으므로(서술형 위주), 실제 치환 대상이 없으면 "치환 대상 0건"으로 로그에 명기한다.

### STEP 5 — 문서 구조 반영
1. 2.5 / 3.5 / 4.5 / 5.5 절 전체 삭제.
2. 결론 장 뒤에 신설:
   ```
   # 제8장 References
   \[1\] ...
   \[2\] ...
   ```
3. 서지 표기 스타일 통일: 현재 장별로 스타일이 혼재(2·3장 IEEE풍 쉼표 구분, 4·5장 ACS풍 세미콜론 구분)하므로, **하나의 스타일로 통일**한다. 기본값: 4·5장에서 쓰인 스타일(저자; 제목. 저널. 연도, 권(호), 페이지. DOI)을 채택하되, 학교 지정 양식이 있으면 그것을 우선한다.
4. 구조 관련 본문 문구 갱신:
   - 목차 앞 안내문의 장 구성 설명에서 "참고문헌" 제거, "참고문헌은 제8장에 통합한다" 명시.
   - 서론의 논문 구성 절에 제2장 Related Work·제8장 References 언급 추가.

### STEP R — 장 번호 재번호화 (최종 단계, 모든 축 완료 후 1회 수행)

1. 장 제목: `제2장 객체탐지...` → `제3장`, ... , `제6장 결론` → `제7장`.

6. ⚠️ 치환은 **충돌 방지를 위해 높은 번호부터 역순으로**(6→7, 5→6, 4→5, 3→4, 2→3) 수행한다.

## 6. 주의사항

- 참고문헌 항목의 **내용(저자·제목·DOI)을 임의로 수정·보완하지 않는다.** 표기 스타일 통일과 명백한 오탈자 교정만 허용하며, 그 외 상충은 기록 후 확인받는다.
- 장 삭제·번호 재부여 과정에서 그림/표 번호(`표 4-1`, `[그림 5-2 ...]`)는 건드리지 않는다.
- 작업 전 git 상태 확인 후, 통합 완료 시점에 단일 커밋으로 남기는 것을 권장한다 (커밋은 사용자 요청 시에만).
