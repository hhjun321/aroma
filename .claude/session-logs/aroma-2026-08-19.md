# Quality 필터 구조 설명 — 코드 실측 기반

코드 확인 결과, "0.7 절대 임계"와 "site 분위 필터"는 **서로 다른 두 필터**다. 파이프라인에 품질 관련 필터가 세 겹 있고, 각각 단위와 방식이 다르다.

```
① void 게이트 (타일 단위, 데이터 도출 분위)
      ↓ 생존 타일로 grid 구성
② site quality 분위 필터 (자리 단위, 하위 15% 배제)
      ↓ 생존 자리만
③ ring argmax (생존 자리 중 site_score 최대 선택)
```

**① void 게이트** — `clean_bg_selection.py:265-293` `_derive_void_floors`. 64px 타일의 LocalVariance·edge energy에 대해 **데이터셋별 p15 분위**를 플로어로 산출. 평탄·무엣지 타일(검은 plate 등)을 배제. hand-set 상수 없음 — §3.2.6 마지막 문단이 서술하는 게 이것.

## 왜 site 단계에서 절대 0.7을 기각하고 분위를 채택했나

절대 임계의 문제 — 분포가 데이터셋마다 이동한다:

- 어두운·저대비 표면(severstal plate): 자리 quality가 전반적으로 낮음 → 0.7 절대컷이면 자리 풀 전멸 또는 fallback 폭주 (aitex 98% 폴백 사례와 같은 계열의 낭비)
- 밝고 깨끗한 표면: 거의 모든 자리가 0.7 통과 → 필터가 아무것도 거르지 않음, 변별력 0

분위 플로어(하위 15%)는 **그 데이터셋 자기 분포 기준으로 최악 자리만** 항상 일정 비율 제거 — 발동률이 데이터셋 간 자동 정규화됨. "hand-set constant 없이 per-dataset 적응"이라는 논문 §3.2.2/3.2.6의 설계 철학과도 일치.

논문의 조건부 유효성 주장은 실제로 **이중 조건**: ① CCI 적정 (활용할 배경 이질성 존재) + ② headroom 잔존. R1-2가 때리는 건 이 주장의 **상관적 형태** ("CCI가 gain을 예측"). 그런데 두 조건 중 **headroom은 직접 조작 가능한 변수**다:

**real_frac 커브 (`--real_frac` 구현 완료, `aroma_exp4v2_real-frac-curve.md`)**
- 같은 데이터셋에서 real 훈련 데이터를 25/50/100%로 축소 → headroom을 인위 개방 → 지점별 Δ(A−R) 측정
- "real이 희소할수록 AROMA 합성이 gap을 더 메운다"의 **단조성** 확인 — n=5 상관이 아니라 **데이터셋 내부 조작 실험**. 통계적 반론 불가 구조
- 설계 완비: severstal+mtd 커브 2종, val 고정(전 지점 동일 평가셋), leakage는 양 arm 대칭이라 Δ(A−R) 유효, GPU 5–8h 추정 (25/50% 지점은 데이터 적어 오히려 저렴)

**CCI 축은 mechanism 증거로 재정위**
- CCI의 mAP 예측력은 n=5 — 방어 불가. 그러나 §4.1 배경 유사도 분해(Figure 4.1-3)는 **데이터셋당 n=200+ 샘플, p<10⁻⁵급** — "CCI 높은 표면에서 placement 신호가 실제로 분별력 있다"는 중간 변수(mechanism) 증거는 통계력 충분
- 즉 CCI 역할을 "성능 예측 지표" → "진단·특성화 지표 + mechanism 근거"로 강등하되, 그 자리를 real_frac 개입 실험이 대신 지탱

## 답변 논리 사슬 (4단)

1. **인정**: n=5로 CCI–gain 상관의 통계적 입증 불가 — "consistent relationship" 표현 철회, "observed pattern" 강등 (기존 계획 유지)
2. **전환**: 조건부 유효성의 검증 가능한 축(headroom)을 real_frac 조작 실험으로 직접 입증 — 상관이 아닌 개입 증거
3. **보강**: CCI는 mechanism 수준에서 데이터셋 내부 통계(n=200+)로 지지됨 — mAP 예측 주장이 아님을 명확화
4. **Limitation**: CCI 예측력의 대규모 roster 검증은 후속 연구

## 리스크

- **커브가 단조 안 나오면 역효과** — Δ(A−R)가 flat이면 논문 반영 불가. 완화: 실험 먼저, 반영은 결과 보고 결정 (ablation과 동일 원칙). 증강 문헌 표준 패턴이라 개연성은 높은 편이나 보장 없음
