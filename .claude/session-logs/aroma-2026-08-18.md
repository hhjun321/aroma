## 현재 구조가 이미 갖고 있는 것

§4.1이 부분 ablation 이미 함 — 단, **mechanism 통계 수준**:
- Figure 4.1-1: ROI 재선정 Random (Stage 1 무력화) → coverage 통계만
- Figure 4.1-3: 같은 ROI + 배경만 랜덤 (Stage 2 무력화, §3.3.4 random_arm) → histogram intersection 통계만

Downstream mAP까지 간 것은 "전부 랜덤" naive Random 하나뿐. **각 단계의 downstream 기여도 분해는 아직 없음** — 여기가 ablation study 자리.

## 가능한 주제 5개

**1. Stage-wise leave-one-out (핵심 추천)**
Full AROMA에서 한 단계씩 랜덤으로 치환, downstream mAP 측정:
- A1: Random ROI + AROMA bg + AROMA site
- A2: AROMA ROI + **Random bg** + AROMA site ← 인프라 이미 존재 (random_arm)
- A3: AROMA ROI + AROMA bg + **Random site**
- 전부 랜덤 = 기존 Random arm (이미 측정됨)

특히 A2가 강력. §4.3에서 Leather 역전(−4.91pp)의 원인을 "bg assignment가 15개 배경으로 collapse → 다양성 손실"로 이미 진단했음. A2를 Leather에서 돌리면 이 가설을 **직접 검증** — Random bg로 다양성 복구 시 성능 회복하면 진단 입증. 논문 서사가 닫힘.

**2. Compatibility model form ablation**
matrix_symmetric = √(P_def·P_clean) 자체를 ablate: P_def only / P_clean only / geometric mean. 세 단계 전부가 이 모델 참조하므로 core 설계 정당화. §3.2.4가 "geometric mean이라 양쪽 조건 동시 필요"라 주장 — 검증 안 된 설계 선택.

**3. Site scoring: distribution matching vs tile averaging**
Figure 3.2.4-2 캡션이 명시적 주장함: "averaging하면 Severstal에서 모든 cluster가 같은 cell로 collapse, matching은 구분 유지". 텍스트에 이미 쓴 주장인데 실험 근거 없음. Severstal 한 데이터셋으로 검증 가능.

**4. ROI_score 가중치 (0.6/0.4)**
ctx_prior only (1.0/0) vs morph_prior only (0/1.0) vs 현행. Figure 3.2.4-3이 "ctx_prior가 지배"라 했으니 morph_prior 0.4가 실제 기여하는지 의문 제기 가능. 단, sensitivity analysis 성격 — 우선순위 낮음.

**5. Quality gate on/off**
§4.1 intro에 "ungated re-selected ROI set" 언급 이미 있음. 메모리상 gate가 random 역전·c2 붕괴 해소한 실측 있으니 formalize 가치 있음 — 다만 gate는 §3.2.6이라 3단계 ablation과는 축이 다름.

## 비용 현실

Downstream ablation 1 arm = 합성 + YOLO 3 seeds × 데이터셋 수. 5개 데이터셋 전부는 낭비 — Kolektor/MTD는 near-ceiling이라 신호 없음 (§4.2/4.3 결론). 권장 축소:
- A1/A3: AITeX + Severstal (AROMA>Random인 곳)
- A2: **Leather 필수** + AITeX
- 주제 3: Severstal만

## 추천 우선순위

1 (leave-one-out, 특히 A2-Leather) > 3 (텍스트 주장 검증) > 2 (core model) > 5 > 4.

주제 1+3 조합이면 "어느 단계가 효과 나르는가" + "설계 선택 정당화" 둘 다 커버하고, 기존 §4.1/§4.3 서사와 직결됨. 방향 정하면 실험 설계 구체화 진행함.

tgt[k] = {A:.373, B:.305, D:.323, ...}   ← 59만 패치가 접힌 비율
h_s    = {A:.50,  B:.17,  D:.33}          ← 타일 6개가 접힌 비율
score  = Σ min = .373 + .17 + .323 = .866

tgt 4단계 재정규화(합=1)가 정확히 이걸 위한 것 — h_s가 합=1이므로 tgt도 합=1이어야 "겹친 질량" 의미 성립 (문서 285행).

> 이해했다. 그렇다면 왜 min 값인가?

🤖 **Claude**

min = "겹침"의 수학적 정의이고, 대안들이 실측으로 죽었기 때문. 세 층으로.

## 1. min이 재는 것 = 두 분포의 공통 질량

"목표가 원하는 양"과 "자리가 가진 양" 중 **작은 쪽까지만** 매칭으로 인정. tgt가 A를 37% 원하는데 자리가 58% 가졌으면, 레시피를 채운 건 37%뿐 — 나머지 21%는 "더 닮음"이 아니라 잉여.

## 2. 대안 죽는 모습 — 숫자로

tgt = {A:.4, B:.3, D:.3}. 자리 둘 비교:

```
자리1 (몰빵):  h_s = {A: 1.0}          ← 타일 전부 최고 인기 셀
자리2 (배합):  h_s = {A:.4, B:.3, D:.3} ← 레시피 그대로

[평균 방식] 타일별 tgt 값 평균
  자리1: 전 타일 A → .4                ← 승리 (!)
  자리2: .4×.4 + .3×.3 + .3×.3 = .34

[min 방식]
  자리1: min(1.0,.4) = .40
  자리2: .4 + .3 + .3 = 1.00           ← 승리
```

평균은 **최고 점수 셀에 몰빵한 자리**가 이긴다 → 전 군집이 데이터셋 최다 표면으로 수렴 → severstal처럼 5개 군집 top-1 셀이 같으면(Q4-1) 전 군집이 같은 자리로 붕괴. min은 초과분을 목표값에서 잘라버려 이 병을 구조적으로 차단 — **배합을 재현해야만 만점**.

실측: ring 유지 + 평균만 쓴 대조 arm(`ring_sgm_mean`) 악화 4/5, 분포 매칭 전환은 개선 5/5 (문서 §2). min이 개선의 원천.

## 3. 발명품 아니라 표준 거리의 쌍대

```
∩(a,b) = Σ min(a,b) = 1 − TV(a,b)     (TV = total variation 거리)
```

min-합 최대화 ≡ TV 거리 최소화. 히스토그램 교집합은 컴퓨터비전 고전 기법(Swain & Ballard). 덤 장점: 0에 강건(KL은 log 0 폭발로 스무딩 필요), 범위 [0,1] 보장, 연산이 min-합 하나로 끝나 전수 스캔 감당(Q10 — severstal 전량 CPU 수 초).

한 줄: 평균은 "좋은 셀 많은 자리"를, min은 "레시피 닮은 자리"를 뽑는다 — 잉여를 인정 안 하는 성질이 몰빵 편향의 해독제고, 그게 TV 거리 최소화와 같은 말이다.
