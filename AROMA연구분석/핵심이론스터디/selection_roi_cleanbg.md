# Selection ③ — 그 배경의 어느 자리에 붙일까 (step3.5 2단계 · `ring_sgm` + 자리 quality 필터)

> 스터디 3부작의 3편. ① 결함 = `selection_defect.md`, ② 배경 이미지 = `selection_clean_bg.md`.
> ②가 고른 배경 pool 각각에 대해 **paste 좌표를 오프라인 확정**한다. step5는 그 좌표를 `forced_xy`로 소비만 한다.

## 0. 선택 순서 (2026-08-11 확정판)

```
① void 게이트 (타일 admissibility)          — 격자 자체를 정의
② admissible 자리 열거
③ 자리 quality 분위 필터 (qf run, 기본 OFF)  — 표면이 나쁜 자리 하위 P15 배제
④ 생존 자리 중 ring score argmax            — 문맥이 맞는 자리 확정
폴백: 자리 0개 → position=None → step5 런타임 배치 (position_source="fallback")
```

## 1. 격자와 admissibility — ① (`_tile_grid` · `_best_ring_site:596`)

**기하 3요소** (상세·그림: QnA Q1·Q2): **s = 핀 꽂는 점**(타일 오프셋 (si,sj), 저장·소비되는 유일한 값),
**F(s) = 핀이 덮는 스티커 면적**(bw×bh 타일 사각형), **R(s) = 스티커 둘레**(테두리 밴드,
타일 수 = 2(bw+bh)+4 — "8이웃"은 방향 규칙이지 타일 8개가 아니다. 경계·void로 감소 가능).

- 배경을 64px **절단 격자**(W//64 × H//64)로 본다 — `_context_worker`와 동일 정책(F1).
  우/하단 나머지(최대 63px)는 **unobserved** — mtd 면적 24.5%가 여기서 버려진다 (위험 4).
- 타일이 grid에 갖는 값 = **context cell key** (텍스처 5특징의 P33/P66 tertile 조합 문자열,
  예 `"2_2_1_2_0"` — Q3·Q4-10). `_patch_void`(분산·엣지 P15 미만) 타일은 격자에서 제외.
- **F는 존재만 묻고, R은 구성을 센다**: admissibility는 F(s) 전 타일의 관측·비-void 여부만 확인
  (`valid(s) ⟺ ∀t∈F(s): observed ∧ ¬void`) — F 타일의 셀 값은 안 읽는다(결함이 덮어 지우므로).
  R의 셀 값들이 ④의 히스토그램 재료다.
- footprint 크기는 **effective(fit-rescale 후)** 크기 기준 (`_effective_wh:458`) — 생성이 실제로 붙일 크기와 일치.

⚠️ **왜 오프라인이 void를 직접 배제하나**: step5의 `forced_xy` 분기(`generate_defects.py:1415-1421`)가
`_positive_place` **앞에서 단락**해 런타임 τ·void 게이트를 전부 우회한다. 게다가 런타임
`_is_clean_background`는 cv2 4.13 fail-open으로 no-op (`aroma_cleanbg_gate_cv2_dtype_failopen.md`).
→ **오프라인 admissibility가 유일하게 동작하는 void 게이트**다.

## 2. ring score — ④의 목적함수

```
tgt[k]  = L1norm(matrix_symmetric[k])          — 군집 k의 목표 문맥 분포 (②의 k_fit과 공유)
h_s(c)  = ring R(s) 타일들의 셀 정규화 히스토그램 (void 제외)
score(k,s) = ∩(h_s, tgt[k]) = Σ_c min(h_s[c], tgt[k][c])
s* = argmax_{valid s} score(k,s)
```

### 재료의 계보 (상세: QnA Q4~Q4-11)

- **tgt[k]** = 데이터셋 전수 인구조사 2번(P_def(k,·)=군집 k 결함 둘레 세상 / P_clean=clean 세상 공용 1행)
  → AND 결합 √곱 → 행 max=1 저장(matrix_symmetric 히트맵) → 사용 직전 합=1 재정규화.
  **peak 셀 하나가 아니라 ~200셀 비율표 전체가 목표다.**
- **구조 = 지도 1개, 질의 N개** (Q4-8): 데이터셋 지도(matrix_symmetric)에 이미지가 h_g로(② k_fit),
  자리가 h_s로(④ ring) 질의를 건다. clean 이미지 1장이 갖는 것은 h_g와 grid뿐.
- **판정 = 구성 매칭** (Q7): 평균도 ✗, "전 타일이 목표 셀" 만장일치도 ✗ — ring 타일들의
  **셀 종류를 세어**(h_s) 목표 비율표와 min-겹침을 잰다. 초과분은 min이 잘라 무기여,
  미관측 셀은 tgt에 없어 자연히 0. 실물 동작은 Figure 3.2.4-2 (QnA Q6 — best/worst 4.3× 변별).

### 왜 ring인가 (footprint가 아니라)

footprint는 결함이 **덮어써 사라지는** 픽셀이다. 합성 후 남아 결함과 접하고 경계 연속성을 결정하는 건 둘레(ring)다.

### 왜 분포 매칭인가 (평균이 아니라) ★ 문서의 심장

평균 argmax는 "높은 점수 셀이 많은 자리"를 고른다. 행 값은 양쪽 풀에서 흔한 셀에서 높으므로
그 목적함수는 **데이터셋에서 가장 평범한 표면으로 수렴**한다. 분포 매칭은 구성을 비교해 이 편향이 상쇄된다
(Figure 3.2.4-2 C의 median 스파이크 — 흔한 셀 몰빵이 min에 잘려 지는 모습이 그 실물).

**기여 분리 실측** (dev_note §3-1(b)) — ring으로 옮기되 평균을 유지한 대조 arm(`ring_sgm_mean`):
- footprint → ring (평균 유지): **악화 4/5** (severstal −0.270 → −0.502)
- 평균 → 분포 매칭: **개선 5/5**
→ 개선의 원천은 위치가 아니라 **score의 정의**다. "ring이 좋다"로 단순화하면 틀린다.
악화 기전: ring은 footprint보다 타일이 **적어서**(테두리뿐) 흔한-셀 편향이 평균에 더 세게 먹는다.

## 3. 자리 quality 필터 — ③ (2026-08-11 신설, `--site_quality_filter`)

- **단위 = 자리(crop-영역)** — CASDA 원 의미 복원. 타일 단위 배제는 severstal 폴백 +20.2p 폭발로 기각
  (세로 관통 footprint가 타일 1개 배제에 전멸하는 비선형).
- quality = CASDA 4-성분(blur 0.3 + contrast 0.3 + brightness 0.2 + noise 0.2), **numpy 전용 구현**(`_np_quality`).
- **분위 플로어 P15** (데이터셋 자기 자리-분포 기준). 절대 0.7 폐기 — leather 자리 max 0.67로 100% 포화 실측.
- 고유 기여 = **밝기 축**: void 게이트(분산·엣지)가 원리적으로 못 보는 밝은 침전물류 (leather 실측:
  배제 타일의 100%가 밝기 극단). 실측 폴백 영향 ≤+0.2p (aitex만 +10.5p — 한계 59%의 1/5, ring 풀 ≥ cap 유지).
- 픽셀이 필요해 `--image_dir` 필수 — step3.5의 "픽셀 불요" 계약의 유일한 예외.

## QnA (스터디 기록)

### Q1. 자리 s와 footprint F(s)의 차이는?

**s = 좌표(점), F(s) = 그 좌표가 결정하는 면적(타일 집합).**

```
s    = 후보 위치 — 타일 오프셋 (si, sj), 좌상단 앵커
F(s) = s에 놓았을 때 덮이는 bw×bh 타일 사각형 (s의 파생물)
R(s) = F(s)의 8이웃 테두리 (역시 s의 파생물)
```

구체 예 (severstal 25×4 격자, 세로 관통 결함 bw=1, bh=4): 후보 s는 25개.
s=(9,0) 선택 → F(s)={(9,0)..(9,3)} → position=(576,0) — annotation `bbox [576,0,…]`과 일치.

| 단계 | 보는 대상 |
|---|---|
| 열거 | s (오프셋 전수 순회) |
| admissibility ① | F(s) — 자격 심사 (하드) |
| quality 필터 ③ | s 앵커의 픽셀 crop-영역 — 표면 심사 (하드) |
| ring score ④ | R(s) — 순위 (소프트) |
| 출력·소비 | s 하나 (픽셀 환산 → step5 forced_xy) |

심사는 F(s)·R(s)에서 하되, 저장·소비되는 것은 s 하나.

### Q2. s / footprint / ring 을 그림으로

**그림 1 — 기본 기하 (bw=2, bh=2), s=(2,1)**

```
    0   1   2   3   4   5
  ┌───┬───┬───┬───┬───┬───┐
0 │   │ R │ R │ R │ R │   │   R = ring R(s) — 합성 후 살아남는 둘레 → ring score가 읽는 곳
  ├───┼───┼───┼───┼───┼───┤
1 │   │ R │ F │ F │ R │   │   F = footprint F(s) — 결함이 덮어쓰는 타일
  ├───┼───┼───┼───┼───┼───┤       → admissibility(①)·quality(③)가 심사하는 곳
2 │   │ R │ F │ F │ R │   │
  ├───┼───┼───┼───┼───┼───┤   s = F의 좌상단 앵커 (2,1) — 픽셀 (128, 64)
3 │   │ R │ R │ R │ R │   │
  └───┴───┴───┴───┴───┴───┘
```

**그림 2 — severstal 실전형 (세로 관통 bw=1, bh=4). ▓=void**

```
     …  7   8   9  10  11 …
  ┌───┬───┬───┬───┬───┬───┐
0 │   │ R │ F │ R │   │▓▓▓│  ← 상단 경계라 위쪽 ring 없음
1 │   │ R │ F │ R │   │▓▓▓│  F가 세로 전체 관통 → ring은 좌·우 기둥만
2 │   │ R │ F │ R │   │▓▓▓│  (부록 R6: severstal 유효 슬롯 평균 2.49의 이유)
3 │   │ R │ F │ R │   │▓▓▓│  ← 하단 경계라 아래쪽 ring 없음
  └───┴───┴───┴───┴───┴───┘  ▓ void 기둥에 F가 겹치는 s는 ① 탈락
```

**그림 3 — 선택 과정**: 후보 s 전수 순회 → F(s) 유효성(①) → crop quality(③) →
∩(R(s), tgt[k]) 계산(④) → argmax s* 하나만 `position=(si·64, sj·64)`로 저장.

**한 줄**: s는 핀 꽂는 점, F는 핀이 덮는 스티커 면적, R은 스티커 둘레 —
심사는 면적과 둘레로, 저장은 핀 하나.

### Q3. F/R 타일에는 무슨 값이 있나? background_type인가?

**아니다 — 타일 값 = context cell key** (텍스처 5특징의 tertile 조합 문자열).

```
CSV(연속값): local_variance, edge_density, texture_entropy,
             frequency_energy, orientation_consistency  (+patch_xy)
   → 각 특징을 데이터셋 자기 P33/P66로 3단 이산화
   → grid[(i,j)] = "2_1_1_1_1"  (cell key — 타일이 갖는 유일한 값)
```

`background_type`(smooth/directional/…)은 **데이터셋당 상수 1개**로 step3 quality_proxy 전용 —
타일 단위 값이 아니며 F/R 어디에도 없다. 완전히 다른 좌표계.

**F와 R의 사용 방식 차이가 핵심**:

| 영역 | cell key 읽나? | 사용 |
|---|---|---|
| F(s) | **안 읽음** | grid 존재 여부만 (관측·비-void) — 어차피 결함이 덮어 지움. qf 필터는 셀이 아닌 F의 픽셀을 봄 |
| R(s) | **읽음** | key들을 세어 히스토그램 h_s 형성 → ∩(h_s, tgt[k]) |

예: R 타일 6개 key {A,A,A,B,B,C} → h_s={A:.5, B:.33, C:.17}.
void 타일은 grid에 없어 F/R 어디에도 등장 불가.

**한 줄**: 타일 값 = 텍스처 5특징 tertile 문자열. **F는 존재만 묻고, R은 구성을 센다.**

### Q4. tgt[k]는 어떻게 만들어지나?

**한 문장**: 군집 k 결함들이 **어떤 표면 옆에서 사는지 인구조사**하고(P_def), 그 표면이
**clean 배경 세상에도 실제로 있는지 교차 확인**한 뒤(P_clean과 AND 결합), **비율표**(합=1 분포)로 바꾼 것.

(코드: phase0가 1~3단계, step3.5 `_target_by_cluster:525`가 4단계)

#### 0단계 — 재료 (Q3 복습)

모든 이미지는 64px 타일로 썰려 있고 타일마다 cell key("2_1_1_1_1")가 붙어 있다.
tgt[k]는 이 **cell들 위의 분포**다. 아래 예제는 셀을 A/B/C/D 4종으로 단순화.

#### 1단계 — 인구조사 2번 (phase0)

```
P_def(k,·) — "군집 k 결함 둘레" 세상          P_clean — clean(good) 세상
(군집 k 결함이 있는 이미지의 배경 타일만,      (good 이미지 전부의 타일)
 결함과 겹치는 타일은 제외)

  A ████████████ .40                          A █████████ .30
  B ██████ .20                                B ████████████ .40
  C ███ .10                                   C  .00   ← clean 세상에 없는 표면
  D █████████ .30                             D █████████ .30
```

- 왼쪽이 "이 형태의 결함은 어떤 표면 옆에서 발견되는가"의 통계
- **결함 겹침 타일 제외**가 중요 — 결함 자신이 아니라 **둘레**의 조사. 그래서 나중에 ring(둘레)과 비교 가능

#### 2단계 — AND 결합 = 기하평균 (√ 곱)

```
raw(c) = √( P_def(k,c) · P_clean(c) )

  A √(.40×.30) = .346   ← 양쪽 다 있음 → 생존
  B √(.20×.40) = .283
  C √(.10×.00) = 0      ← 결함은 그 옆에 살지만 clean에 없음 → 목표 자격 박탈
  D √(.30×.30) = .300
```

**왜 AND인가**: "결함이 사는 문맥"만 보면 clean 배경에서 **찾을 수 없는 목표**가 되고,
"clean에 흔한 표면"만 보면 **아무 데나** 붙이게 된다. 둘 다 만족해야 목표 자격.
(ε=10⁻³ 스무딩이 진짜 0 대신 미세값을 넣어 절벽을 완화 — C는 사실상 0)

#### 3단계 — 저장용 정규화: 최대=1 (matrix_symmetric)

```
행을 max(.346)로 나눔:   A 1.00   B .818   D .867
```

읽는 법 = "이 군집의 **최적 셀 대비 몇 %**". 합이 1이 아니라 **확률분포가 아니다** —
히트맵(논문 Figure 3.2.4-1, 각 행 peak=1)용 저장 형식.

#### 4단계 — 사용 직전 재정규화: 합=1 (tgt[k], step3.5)

```
합(2.685)으로 나눔:      A .373   B .305   D .323     ← tgt[k]
```

**막대의 '모양'은 3단계와 완전히 같다** — 전부 같은 수로 나눴으니(단조 rescale).
바뀐 건 눈금뿐: "최적 대비 %" → "전체 중 비율". 이것이 "논문 수식 무수정" 주장의 근거.
왜 필요한가: 교집합 상대인 h_s가 합=1이므로 tgt도 합=1이어야 "겹친 질량"이라는 의미가 성립.

#### 사용 — ring 히스토그램과 겹쳐 보기

```
자리 s의 ring: 타일 6개 = {A,A,A,B,D,D} → h_s = {A:.50, B:.17, D:.33}

        tgt[k]           h_s              min (겹침 = 점수 기여)
  A     ▓▓▓▓▓▓▓ .373     ██████████ .50   ▓▓▓▓▓▓▓ .373  ← 초과분 .127은 기여 없음
  B     ▓▓▓▓▓▓ .305      ███ .17          ███ .17
  D     ▓▓▓▓▓▓ .323      ██████▌ .33      ▓▓▓▓▓▓ .323
  C     (없음)            (있어도)         0              ← 미관측 셀 = 자연스러운 0

  score = .373 + .17 + .323 = .866
```

- **A의 초과분이 기여하지 않는 것**이 "흔한 셀 몰빵" 차단 기전 — 평균 방식이 갖던 편향의 해독제
- **C의 자연스러운 0** — 행에 없는 셀은 tgt에도 없어 기여 0. 런타임 `_positive_place`의
  `.get(cell, 0.5)` 중립 처리(미관측 셀에 0.5 부여)와 대비되는 지점

같은 tgt[k]를 ②(k_fit — 배경 **전체** 히스토그램과)와 ③(ring — 자리 **둘레**와) 공유 — Q5 참조.

### Q5. k_fit(1단계)과 R(2단계)의 연결 상세

**같은 tgt[k]에 두 번 조준 — 전역(공급 확인) → 국소(위치 특정).**

```
k_fit = ∩(h_g, tgt[k])   h_g = 이미지 전체 비-void 타일 히스토그램 (수백~수천 타일)
ring  = ∩(h_s, tgt[k])   h_s = 자리 둘레 6~20타일 히스토그램
```

- **ring 혼자 안 되는 이유**: argmax는 랭킹이라 절대 실패하지 않는다 — 나쁜 배경에서도 "그중 최선"을
  내놓는다. **2단계는 1단계가 공급한 것 이상을 만들 수 없다** (k_fit이 천장, ring이 그 아래 위치 특정).
- **k_fit 혼자 안 되는 이유**: h_g는 전체 집계라 "어디에"를 모른다 — 목표 혼합이 흩어진 경우와
  한 구역에 모인 경우를 구분 못 함.
- **분산 차이**: h_g 안정 / h_s 거침(타일 1개가 5~17%p) — 1단계는 미세 랭킹, 2단계는 구성 매칭 수준.

미묘한 지점 2개:
1. **P_clean 정당성이 단계마다 다르다** (§2-2): 1단계 정당(가용성 질문 유효), 2단계는 어색하나 **유지** —
   R4 실측(P_clean 제거 재정의)이 개선 실패 + 수식 무수정이 논문 구조 보존.
2. **greedy, joint 아님** (위험 8): 1단계 확정 후 2단계 argmax — 버려진 이미지 속 완벽한 자리는 못 찾는다.
   P1 검증도 배경 무작위 고정으로 쟀으므로 **k_fit 선정 배경 위 ring 성능(상호작용)은 미측정**.

예: tgt={A:.57,B:.29,C:.14}. g1(A20%+B10%+C5%, k_fit=.35)이 pool에 오르고,
2단계가 g1 안에서 A·B가 실제로 모인 구역의 자리를 특정 — 흩어져 있으면 최고 ring도 낮다(1단계는 몰랐던 정보).

### Q4-1. 예제의 A/B/C/D는 cell key의 단순화인가?

**맞다.** A ≡ "0_0_0_1_0" 식으로 실제 cell key 문자열 하나씩을 대신한다.
실물 규모(severstal 실측): 이론 3⁵=243 셀 중 군집당 **192~197개 관측**, 군집 5개(행 5개 = tgt 5개).

덤 관찰: severstal은 **5개 군집 전부 top-1 셀이 동일**("0_0_0_1_0" — 균일 강판면).
논문 Figure 3.2.4-1의 "전 군집이 dominant cell 공유"의 실물이며, 평균 argmax였다면
전 군집이 같은 자리로 붕괴했을 조건 — 분포 매칭은 나머지 190여 셀의 구성 차이로 자리를 구분한다.

### Q4-2. (2단계) 측정 범위와 √곱의 기준 영역은?

**범위 = 데이터셋 전체 patch 전량** (이미지 1장 아님):
- P_clean: 전 good 이미지의 전 타일 (severstal ≈ 5,902장 × ~100타일 ≈ 59만 패치)
- P_def(k,·): "군집 k 결함 보유 이미지들"의 전 배경 타일 — 이미지 부분집합 제한 + 결함 겹침 타일 제외

**√곱의 단위 = cell** (bbox도 patch도 아님). 용어 교정: 2단계는 교집합(∩)이 아니라 **셀별 곱(기하평균)** —
`raw(k,c) = √(P_def(k,c)·P_clean(c))`, 같은 셀끼리 1:1 스칼라 곱. 2단계 도달 시점에 patch는 이미
cell 인구수로 접혀 사라진 상태다. bbox/mask의 역할은 1단계에서 "결함 겹침 타일을 P_def에서 제외"하는
판정 하나로 끝났다. (∩는 4단계 이후 사용 시 h_s↔tgt 비교 연산.)

### Q4-4. P_def는 "k 결함별 특징의 이미지 통계치"인가?

**절반 — "k별로"는 맞고, "결함 특징의 통계"는 틀리다.**

- 결함의 형태 특징(AR·solidity…)의 역할 = GMM으로 **군집 라벨 k를 정하는 것뿐** — 거기서 퇴장
- P_def(k,·)의 내용물 = **라벨 k 이미지들의 "배경" 타일**(결함 겹침 제외)의 cell 인구조사 — 결함 픽셀·특징 0%

비유: "키 큰 사람들의 통계"가 아니라 "키 큰 사람들이 사는 **동네**의 통계" — 키는 묶는 데만 쓰였다.
k = 누구를 셀지(그룹핑 키), 세는 대상 = 그들의 이웃(배경). 이 교차가 matrix_symmetric(k,c) =
"이 형태의 결함은 어떤 표면 옆에서 사는가".

결함 겹침 타일 제외의 이유 재확인: 결함 픽셀이 섞이면 배경 통계가 오염돼 ring(순수 배경 둘레)과
비교 단위가 어긋난다 — 부록 R7 실측(bbox 접촉 타일의 72~96%가 결함 픽셀 포함).

### Q4-5. P_clean도 같은 방식의 배경 타일 통계인가?

**맞다 — 기계는 동일(타일→cell→인구조사), 모집단·조건이 다르다:**

| | P_def(k,·) | P_clean |
|---|---|---|
| 모집단 | 군집 k 보유 결함 이미지들 | **good 전부, 조건 없음** |
| 제외 | 결함 겹침 타일 | 없음 — 전 타일이 정의상 배경 |
| 개수 | 군집 수만큼 (sev 5개) | **1개 — 전 군집 공용 행** |
| 의미 | 군집별 선호 ("그 옆에 사는가") | 공용 가용성 ("clean에 존재하는가") |

행렬의 행마다 달라지는 건 P_def뿐, P_clean은 모든 행에 같은 값으로 곱해진다 —
기하평균에서 P_def=선호, P_clean=가용성 필터 역할 분담 (Q4 예제 C의 자격 박탈이 후자).

### Q4-6. P_clean은 clean 이미지 전체를 다 계산하는가? (100개면 100개 다?)

**그렇다 — 전수.** severstal 실측: good **5,902/5,902 전부** (패치 590,200행), defect 3,620/3,620 (346,569행)
— context_features.csv에 한 장도 빠짐없이 존재. P_clean = 이 590,200 패치 전량의 인구조사.

전수/표본 경계선: phase0 프로파일링·valid pool 심사·배경 랭킹(ROI×유효배경 전수, sev 535만 조합)까지
**모델 경로는 끝까지 전수**. 표본은 CCI(20k 패치 — 복잡도 요약용)와 P1 검증 실험(배경 30장 — 평가 설계)
뿐 — 둘 다 호환성 모델 밖. 전수가 감당되는 이유 = 타일 특징이 싼 연산 + 랭킹이 히스토그램 교집합 1회.

### Q4-7. 논문 Figure 3.2.4-1 (mtd 히트맵) 읽기 — matrix_symmetric의 시각화

### Q4-9. 히트맵 x축이 c1~c20뿐인 것의 의미는?

**교정 먼저**: c = patch가 아니라 patch들이 소속되는 **범주(칸)** — patch:cell = 다:1.

- **표시 절단**: mtd 실제 관측 셀 행별 116~187종 중 그림은 상위 20만. **tgt[k]는 전 셀 사용** — 모델 절단 아님.
- **선정·정렬 규칙** (그림 스크립트 `[figure 3.2.5 2]` 확정):
  선발 = max-across-clusters(어느 군집에서든 최대값 큰 20개), 정렬 = mean-compat 내림차순.
  → 왼쪽 = 군집 공통 선호 + peak들(빨간 박스 몰림), 오른쪽 = 선호가 갈리는 셀(k4 행 흰 칸들).
- **c번호는 데이터셋-국소 별칭**: mtd c1 = "2_2_1_2_0", severstal c1과 무관. 그림 간 열 비교 무의미 —
  행 내부의 패턴(peak 위치·분화)만 읽는다.

### Q4-10. c1, c2, c3…은 서로 어떻게 구분되는가?

**cell key 5자리 코드 판독** — 각 셀 = 텍스처 조합으로 정의된 "표면 유형" 하나:

```
"2_2_1_2_0" = [local_variance, edge_density, texture_entropy, frequency_energy, orientation_consistency]
```

### Q8. 목적함수 블록 4줄 해부

| 줄 | 역할 | 핵심 성질 |
|---|---|---|
| ① tgt[k] | **과녁** — 군집당 1개 상수 (루프 밖 1회 계산) | 자리·이미지 무관, ~200셀 비율 명세서 |
| ② h_s | **응시자** — 자리당 재계산 | **입도 1/n** (ring n타일 → n=20이면 5% 단위 계단) — tgt(전수·연속)와의 해상도 비대칭이 본질적 거칠기. 분모=생존 ring 타일 수 |
| ③ score | **채점기** | 아래 성질 4개 |
| ④ argmax | **집행자** | 정의역=valid(s)만(자격은 상류 담당) · 결정적(스캔 순서 고정+엄격 부등호 → 동점 시 선착순, rng 없음 — 좌표 불변의 근거) · 출력 s 하나+site_score 기록 |

**③의 성질 4개**:
1. 범위 [0,1], 1 ⟺ 완전 일치 (best 0.210 = 21% 겹침)
2. **∩(a,b) = 1 − TV(a,b)** — 교집합 최대화 ≡ total variation 거리 최소화. 발명품이 아니라 표준 거리의 쌍대
3. 초과 무기여 (min이 목표값에서 자름) — 평균 방식 병의 구조적 해독제
4. 범주형 무자비 — 근사 셀 부분점수 없음 (대가로 연산이 min-합 하나)

역할극: **과녁(상수) ← 채점기(TV쌍대) ← 응시자(소표본 구성비) → 집행자(자격자 중 결정적 1등)**

### Q13. footprint 크기·모양은 무엇으로 정해지는가?
