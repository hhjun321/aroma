### 순차적 배치 결정

합성 배치 과정은 세 가지 순차적인 결정으로 분해된다.
(i) **어떤 결함을 소스로 사용할 것인가(ROI 선택)**,
(ii) **선택된 결함을 어떤 정상 배경 이미지에 배치할 것인가(배경 배정)**,
(iii) **선택된 배경의 어느 위치에 배치할 것인가(자리 확정)**이다.

이 세 단계는 이전 단계에서 측정한 **결함–배경 호환성 정보**를 이어서 활용한다. ROI 선택에서는 결함의 형태 및 문맥 특성을 이용하여 합성에 사용할 결함을 결정하고, 
배경 배정에서는 선택된 결함과 특성이 유사한 정상 배경 이미지를 탐색한다. 마지막 자리 확정에서는 선택된 배경 이미지 내 후보 위치의 국소 문맥을 평가하여 가장 적합한 위치를 결정한다.

각 단계에서 공통적으로 활용되는 호환성 모델인 `matrix_symmetric`을 먼저 정의한다.

### 호환성 모델: `matrix_symmetric`

`matrix_symmetric`은 형태 군집 (k)와 64 px 크기의 이산 문맥 셀 (c) 사이의 호환성을 나타내는 모델이다. 
이 모델은 두 개의 관측 확률 분포로부터 구성된다. 
P_def(k, c) 는 형태 군집 (k)에 속하는 결함이 존재하는 이미지에서 관측된 문맥 셀의 분포이며, 
P_clean(c) 는 전체 정상 이미지에서 관측된 문맥 셀의 분포이다.

먼저 두 분포의 기하평균을 이용하여 문맥 호환성을 계산한다.

ctx_prior(k, c) ∝ √( P_def(k, c) · P_clean(c) )

이후 각 형태 군집 (k)에 대해 행 단위로 정규화하여 최종 호환성 모델을 구성한다.
따라서 `matrix_symmetric`의 각 행은 특정 형태 군집 (k)에 대해 각 문맥 셀이 갖는 **상대적 호환성**을 나타내며, 해당 군집에서 가장 호환성이 높은 문맥 셀의 값은 1이 된다.
이 호환성 모델을 기반으로 전체 합성 과정은 다음 세 단계로 수행된다.

---

### 1. ROI 선택

ROI 선택 단계에서는 **어떤 결함을 합성의 소스로 사용할 것인지**를 결정한다. 후보 결함은 형태 군집과 해당 결함이 관측된 문맥 특성을 기준으로 표현되며, 각 후보의 호환성 점수를 계산하여 상위 (K)개의 후보를 선택한다.

후보의 점수는 문맥 기반 호환성과 형태 군집의 사전확률을 결합하여 다음과 같이 계산한다.
ROI_score = 0.5 · ctx_prior + 0.3 · morph_prior + 0.2 · quality 

여기서 morph_prior 는 §3.2.2에서 정의한 형태 군집의 사전확률 (P(k))이며, ctx_prior 는 `matrix_symmetric`으로부터 얻어지는 문맥 기반 호환성 값이다.
두 분포는 동일한 이산 문맥 셀 공간에서 정의된다. 
P_clean(c)는 전체 정상 이미지의 64 px 문맥 패치로부터 추정하고, 
P_def(k, c)는 형태 군집 (k)에 속하는 결함이 포함된 이미지의 문맥 패치로부터 추정한다. 
두 분포의 기하평균을 사용함으로써 결함이 관측된 문맥과 정상 이미지에서 실제로 존재하는 문맥을 동시에 고려할 수 있다.
계산된 `matrix_symmetric`은 각 형태 군집에 대한 문맥 호환성 프로파일을 제공하며, 이를 이용하여 후보 결함을 정렬한다. 
최종적으로 `ROI_score`가 높은 상위 (K)개의 결함 후보를 이후 배치 과정의 소스로 사용한다.

---

### 2. 배경 배정

ROI가 선택되면, 합성에 사용할 **정상 배경 이미지**를 결정한다.
배경 후보는 프로파일에서 추출한 세 가지 적합도인 `src_fit`, `class_fit`, `size_fit`을 이용하여 순위를 매긴다.

두 개의 정규화된 분포 (a)와 (b)에 대한 히스토그램 교집합은 다음과 같이 정의한다.
∩(a, b) = Σ_c min( a(c), b(c) )
이를 이용하여 각 배경 이미지 (g)에 대한 세 가지 feature를 다음과 같이 계산한다.

src_fit(g) = ∩( h_g, p_src(v) )
class_fit(g) = ∩( h_g, p_cls )
size_fit(g) = min( 1, 0.95 · W_g / w, 0.95 · H_g / h )
여기서 (h_g)는 후보 정상 이미지 (g)의 문맥 셀 히스토그램을 의미한다.
각 feature는 서로 다른 측면의 배경 적합성을 평가한다. 
`src_fit`은 **선택된 결함 ROI가 추출된 원본 이미지의 문맥 특성을 후보 배경이 얼마나 가지고 있는지**를 나타낸다. 
`class_fit`은 **해당 결함 class와 연관된 이미지 특성을 후보 배경이 얼마나 가지고 있는지**를 나타낸다. 
특히 하나의 이미지에 여러 defect label이 존재할 수 있는 multi-label 데이터셋에서도 class-level 특성을 반영할 수 있도록 구성된다.
`size_fit`은 **선택된 결함 ROI가 후보 배경 이미지에 적절한 크기로 들어갈 수 있는지**를 평가한다. 
즉, 단순한 문맥 유사도뿐 아니라 실제 ROI의 크기와 배경 이미지의 가용 영역을 함께 고려한다.


세 feature를 합산하여 최종 배경 점수를 계산한다.
bg_score = src_fit + class_fit + size_fit 

각 후보 배경의 점수를 비교하여 가장 높은 점수를 갖는 정상 이미지를 선택된 ROI의 배경으로 배정한다.

### 3. 자리 확정

배경 이미지가 결정된 이후에는 **선택된 결함을 해당 이미지의 어느 위치에 배치할 것인지**를 결정한다. 이 단계에서는 선택된 결함의 형태 군집과 배경 이미지 내 후보 위치의 국소 문맥을 직접 비교한다.
선택된 결함의 형태 군집을 (k), 후보 배치 위치를 (s)라고 정의한다. (s)는 결함 crop의 좌측 상단 좌표를 의미한다. 각 후보 위치에서는 결함 crop의 주변 영역을 **ring 영역**으로 추출한다. Ring은 실제 결함이 배경에 삽입되었을 때 결함 주변에 형성되는 국소 문맥을 나타내며, 후보 위치의 주변 환경을 평가하는 데 사용된다.
각 후보 위치 (s)의 ring 영역을 64 px 문맥 셀의 배열로 변환하여 히스토그램 (h_s)를 구성한다. 이후 해당 결함의 형태 군집 (k)에 대응하는 `matrix_symmetric`의 행을 target profile로 사용한다.

따라서 후보 위치의 site score는 다음과 같이 계산된다.

site_score = ∩(h_s, tgt[k])
즉, 선택된 결함이 실제로 관측된 문맥 특성과 후보 위치 주변의 국소 문맥이 얼마나 유사한지를 히스토그램 교집합으로 측정한다. 
모든 후보 위치에 대해 `site_score`를 계산한 후, **가장 높은 점수를 갖는 위치를 최종 배치 위치로 선택한다.**

이 과정을 통해 결함 배치는 단순한 기하학적 조건이나 무작위 위치 선택에 의존하지 않고, **해당 결함 형태가 실제 데이터에서 관측된 문맥과 가장 유사한 위치**를 선택하도록 결정된다.

ROI 선택에서는 **어떤 결함을 사용할지**를 결정하고, 배경 배정에서는 **어떤 정상 이미지에 결함을 삽입할지**를 결정하며, 자리 확정에서는 **선택된 이미지의 어느 위치가 해당 결함에 가장 적합한지**를 결정한다.
이때 `matrix_symmetric`은 결함 형태 군집과 문맥 셀 사이의 호환성을 공통된 표현으로 제공한다. 따라서 AROMA는 결함 자체의 형태뿐 아니라 **결함이 관측되었던 배경 문맥과 새롭게 배치될 위치의 국소 문맥을 함께 고려하여 합성 위치를 결정**할 수 있다.
