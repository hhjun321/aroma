### 3.2.4 ROI 선택과 호환성 기반 배치

**[도입 — 신설]** 합성 배치는 세 개의 순차 결정으로 분해된다: (i) 어떤 결함을 소스로 쓸 것인가(ROI 선택), (ii) 그 결함을 어느 clean 배경 이미지에 붙일 것인가(배경 배정), (iii) 그 배경의 어느 위치에 붙일 것인가(자리 확정). 세 결정은 하나의 공통 기반을 공유한다 — 프로파일링이 데이터셋마다 한 번 구축하는 결함-배경 호환성 모델이며, 배경 배정은 이를 이미지 전체 스케일로, 자리 확정은 후보 위치의 국소 둘레 스케일로 질의한다. 이 절은 모델을 한 번 기술한 뒤 세 결정을 순서대로 기술한다.

**[ROI 선택]** 후보 (결함, 문맥) 쌍 전체를 호환성 점수로 정렬해 상위 K개를 취한다. 형태 군집별 기본 quota가 커버리지를 보장하고, 다중 클래스 데이터셋에서는 클래스별 균일 floor가 특정 클래스의 기아를 방지한다. 순서 기준은

  ROI_score = 0.6 · ctx_prior + 0.4 · morph_prior

이며, ctx_prior는 아래에서 정의하는 프로파일 유래 호환성, morph_prior는 §3.2.2의 군집 prior P(k)다. 두 혼합 가중치는 모든 데이터셋에 동일하게 0.6/0.4로 고정된다 — 데이터셋별 튜닝을 도입하지 않는다는 뜻이며, 혼합비 자체가 데이터에서 유도되었다는 주장은 아니다; 점수는 호환성 항이 지배하고, 군집 prior는 주로 호환성이 포화된(ctx_prior = 1) 후보들의 순서를 정한다. 형태 붕괴를 막기 위해 각 소스 결함 크롭은 최대 한 번만 선택된다.

**[호환성 모델 — 공통 기반]** 모든 배치 결정이 참조하는 것은, 형태 군집 k와 64px 문맥 셀 c를 두 관측 확률의 기하평균으로 채점하는 대칭 호환성 게이트다:

  ctx_prior(k, c) ∝ √( P_def(k, c) · P_clean(c) )

두 인자는 같은 이산 셀 공간 위의 셀-빈도 분포로, 64px 배경 패치를 세어 합이 1이 되도록 정규화한 것이다. P_clean(c)는 전체 정상 이미지의 패치로부터, P_def(k, c)는 군집 k의 결함을 가진 이미지들의 패치로부터 추정하되, 각 패치는 자기 이미지의 군집 라벨을 상속하고 결함 영역과 겹치는 패치는 프로파일링에서 제외된다 — 따라서 P_def는 결함 자신이 아니라 **군집 k 결함을 둘러싼 배경 문맥**을 기술한다. 곱의 제곱근은 두 인자의 기하평균이다: 두 인자에 대칭이며 어느 한쪽이 소멸하면 0으로 붕괴하는데, 이를 막는 것이 아래의 가산 스무딩이다. 비례식으로 쓰는 이유는 저장되는 점수가 이 기하평균을 군집별 최대값으로 나눈 것이기 때문이다 — 각 군집의 최적 셀이 1이 된다. 가산 스무딩(ε = 10⁻³)이 두 인자에 적용되고, 군집별 점수는 최적 셀이 1이 되도록 재척도된다; 이 행-정규화 값이 프로파일링 단계가 matrix_symmetric으로 저장하는 것이다. 기하평균은 두 확률이 모두 높을 때에만 높아, 결함 쪽과 배경 쪽을 대칭으로 가중한다. 패치 격자는 타일 단위로 절단되므로 이미지 우/하단의 타일 미만 잔여 영역은 셀을 갖지 않는다; 이런 타일은 미관측(unobserved)으로 분류되어 모델이 질의되는 모든 지점에서 제외된다.

군집의 호환성 행은 셀별 점수표가 아니라 **목표 문맥 분포**로 소비된다. 행을 합이 1이 되도록 재정규화하면 — 상대 형태를 바꾸지 않는 단조 재척도다 —

  q_k(c) = ctx_prior(k, c) / Σ_c′ ctx_prior(k, c′)

를 얻고, 아래의 배경 배정과 자리 확정이 두 개의 별개 양이 아니라 **이 단일 분포 하나**를 질의한다.

**[배경 배정]** 합성 전에, 각 ROI에는 프로파일 유래 cue들로 순위를 매긴 clean 배경이 배정된다. 모든 cue는 이산 문맥-셀 공간 위의 히스토그램 교집합으로, 두 분포 a, b에 대해

  ∩(a, b) = Σ_c min( a(c), b(c) )

로 쓴다. v를 ROI의 소스 결함, k를 그 형태 군집, (w, h)를 bounding-box 크기, g를 치수 (W_g, H_g)의 후보 clean 배경이라 하자. h_g를 g의 비-void 타일 위 문맥-셀 히스토그램, p_src(v)를 v의 소스 이미지 배경 셀 분포, p_cls를 v의 클래스 집계 배경 분포라 하면, 네 cue는

  u_src(g) = ∩( h_g, p_src(v) )
  u_cls(g) = ∩( h_g, p_cls )
  u_mor(g) = ∩( h_g, q_k )
  u_siz(g) = min( 1, 0.95 · W_g / w, 0.95 · H_g / h )

이고, u_siz는 paste가 적용할 fit-rescale 배율로 크롭이 무왜곡 적재될 때 1이다. 순위 점수는 가중합

  U(g) = Σ_j w_j · u_j(g),   j ∈ { src, cls, mor, siz }

이며, 가중치는 수동 설정이 아니라 각 cue의 측정된 변별 lift에서 유도된다. G를 한 ROI의 유효 배경 풀이라 하면 cue j의 lift는 최고 후보와 중앙 후보의 격차를 ROI에 대해 평균한 것으로,

  λ_j = E_ROI [ max_{g∈G} u_j(g) − median_{g∈G} u_j(g) ],   w_j = λ_j / Σ_j′ λ_j′

풀 전반에서 평탄한 cue는 아무 기여도 못 하며 순위를 왜곡할 수 없다. cue u_mor는 후보 배경이 군집 k의 결함이 점유하는 문맥 셀을 실제로 공급하는지를 묻는다 — u_cls와 중복이 아니다. 클래스 축과 형태 군집 축은 같은 결함 모집단의 서로 다른 분할이어서(Severstal은 클래스 4개에 군집 5개, MVTec Leather는 클래스 5개에 군집 3개), 한 클래스의 결함이 여러 군집에 걸치는 일과 그 역이 일상적으로 일어난다.

**[자리 확정]** paste 위치는 합성 시점이 아니라 **선택 시점에 해소된다** — 합성은 여기서 확정된 좌표를 소비할 뿐 추가 위치 탐색을 하지 않는다. 확정은 모델이 구축된 것과 같은 64px 타일 격자 위에서 진행된다. 후보 위치 s는 결함의 (fit-rescale 후) bounding box가 적재되는 임의의 타일 오프셋으로 — 후보 창의 크기와 종횡비는 개별 결함의 bbox가 그대로 정하며, 군집은 목표 분포 q_k만 기여한다 — 두 타일 집합을 결정한다: 결함이 덮을 **footprint** F(s), 그 사각형의 8이웃 테두리 **ring** R(s). 위치는 footprint 전체가 관측·비-void일 때에만 허용된다:

  valid(s) ⟺ ∀ t ∈ F(s) : t는 관측이고 void가 아님

이 조건은 사용 불가 영역에 걸친 후보를 채점 전에 배제한다(§3.2.6). footprint에 대해서는 이 존재 확인만 수행한다 — 그 셀 값은 paste가 덮어쓸 것이므로 읽지 않으며, 셀 값이 채점에 들어가는 곳은 ring뿐이다. 허용된 위치의 ring 셀들은 비-void 타일 위에서 정규화 히스토그램

  h_s(c) = |{ t ∈ R(s) : cell(t) = c }| / |{ t ∈ R(s) }|

로 집계되고, 위치는

  score(k, s) = ∩( h_s, q_k ),   s* = argmax_{s : valid(s)} score(k, s)

로 채점·선택된다. 이 규칙은 필터가 아니라 순위다: 허용 위치에 합격선을 두지 않고 상대 최선을 취하며, 절대적 적합성의 확보는 위의 배경 배정 단계가 담당한다.

이 규칙의 두 성질은 의도된 것이다. 첫째, footprint가 아니라 **ring을 읽는다** — footprint는 붙인 결함이 정확히 덮어쓰는 영역이고, 합성에서 살아남아 블렌딩 뒤 결함과 접하는 것은 ring이다. 둘째, ring을 스칼라로 평균하지 않고 **분포로 매칭한다**. 호환성 행을 타일 위에서 평균하는 목적함수는 개별 고점 셀을 많이 가진 위치를 보상하는데, 행 값은 두 모집단 모두에서 흔한 셀에서 정확히 높으므로 그 목적함수는 배치를 데이터셋의 가장 평범한 표면으로 몰아간다 — 실제 결함이 점유하는 문맥 분포의 재현과는 정반대다. ring의 구성을 q_k에 매칭하면 그 견인이 제거된다: 위치 주변 표면들의 혼합이 군집 k의 결함 주변에서 관측된 혼합을 닮을 때에만 점수가 높아지고, 단지 흔한 셀의 과잉은 — 원소별 min이 초과분을 목표치에서 잘라내므로 — 그 자체로는 점수를 올리지 못한다.

어떤 배경에서 valid(s)를 만족하는 위치가 하나도 없을 수 있다 — 예컨대 결함의 타일 사각형이 절단 격자보다 크거나 사용 가능 영역이 조각난 경우다. 그때 선택 단계는 위치를 방출하지 않고 해당 ROI는 합성기 자체의 배치 탐색으로 폴백하므로, 이 규칙은 허용 위치들 위의 선호이지 경성 요구가 아니다.

이 데이터 유도 호환성 게이트는 CASDA의 수작업 호환성 행렬을 프로파일링 통계에서 직접 유도된 데이터셋별 대응물로 자동 대체한다. 반면 Random 기준선은 호환성 기반 순위를 일절 수행하지 않으며, AROMA와는 ROI 배치 기구에서만 다르다.
